الهدف: **خطوات أقل**. كل ما يمكن أتمتته — تثبيت اللعبة، وجمع المودات وحزم المودات، وتعديل الإعدادات، وقراءة السجلات — يتولاه وكيل الذكاء الاصطناعي.

## ✨ الجديد في 28.1.0

- **إجراء الامتثال عند أول تشغيل**：ثلاثة مستندات مدمجة — ① اتفاقية الترخيص + سياسة الخصوصية، ② إشعار المصادر المفتوحة لأطراف ثالثة + إخلاء المسؤولية والمخاطر، ③ دليل الاستخدام + المناطق المشمولة والاختصاص القضائي. يجب **التمرير إلى نهاية كل مستند وتأكيده على حدة**، ثم اختيار الفئة العمرية (المستخدمون الحاليون يمرّون بالخطوة مرة واحدة بعد التحديث أيضًا).
- **نافذة زمنية للقاصرين**：من هم دون 18 عامًا لا يمكنهم تشغيل اللعبة إلا أيام الجمعة والسبت والأحد والعطلات الرسمية من **20:00 إلى 21:00**؛ عطلات 2026 مذكورة يومًا بيوم وفق تقويم مجلس الدولة الصيني (国办发明电〔2025〕7号)، وأيام التعويض تُعامل معاملة أيام العمل.
- **إخلاء المسؤولية مكتوب بالكامل**：فقدان الحفظ، وسخونة الجهاز، والحظر من أطراف ثالثة، وتوقف الخدمة، ومخاطر مشابهة، كلها معلنة صراحة.
- **كذلك**：لم تعد بطاقات الصفحة الرئيسية تعلق عند التحميل، وبحث الويب في الذكاء الاصطناعي يعمل، والاستيراد يذهب إلى مجلد النسخة، وأُزيل الإصلاح التلقائي بعد الانهيار.

> 🌍 **المناطق المتاحة في 28.1.0**：الصين والولايات المتحدة وكوريا الجنوبية واليابان وروسيا. في المناطق الأخرى تظهر صفحة توضيحية عند أول تشغيل ثم يُغلق التطبيق بأمان.

## 🛠️ ما الذي يستطيعه

- **وكيل الذكاء الاصطناعي**：DeepSeek افتراضيًا — يثبّت اللعبة وحزم المودات والمودات، ويعدّل الإعدادات، ويقرأ السجلات، ويشغّل اللعبة
- **أنظمة العرض**：تلقائي / MobileGlues / GL4ES / LTW (تجريبي)
- **نواة الموارد**：البحث في Modrinth / CurseForge، وحل الاعتماديات، والتنزيل، والتحقق، والتثبيت
- **المفضلة والأرشيف**：مفضلة عبر الإنترنت + أرشيف خاص، مع إزالة التكرار بـ SHA-256
- **حماية Fabric API**：تُضاف Fabric API / Quilted Fabric API / Legacy Fabric API عبر مسار التثبيت — لا تكرار ولا بحث ولا حذف
