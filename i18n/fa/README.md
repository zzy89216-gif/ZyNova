# ZyNova

> ⭐ **ZyNova 28.1.0 منتشر شد (نسخهٔ هم‌راستا با الزامات جهانی).**

[![Platform](https://img.shields.io/badge/Platform-Android-brightgreen)](https://developer.android.com/)
[![Release](https://img.shields.io/badge/Release-28.1.0-purple)](https://github.com/zzy89216-gif/ZyNova/releases/tag/v28.1.0)

---

لانچر **Minecraft: Java Edition** برای اندروید که مستقل از کد ZalithLauncher2 نگهداری و منتشر می‌شود. این یک بیلد رسمی نیست.

هدف: **لمس کمتر**. هر کاری که بتوان خودکار کرد — نصب بازی، جمع‌کردن مادها و مادپک‌ها، تغییر تنظیمات، خواندن لاگ‌ها — به عامل هوش مصنوعی سپرده می‌شود.

- GitHub：<https://github.com/zzy89216-gif/ZyNova>
- خطاها و پیشنهادها：<https://github.com/zzy89216-gif/ZyNova/issues>
- Discord：<https://discord.gg/QwPpZQHrTa>
- X (حساب اصلی رسمی)：<https://x.com/ZyNovaProject>
- ایمیل اکوسیستم چین：<ZyNovaLauncher@163.com>
- ایمیل جهانی：<ZyNovaLauncher@outlook.com>

## ✨ تازه‌های 28.1.0

- **فرایند انطباق در نخستین اجرا**：سه سند ادغام‌شده — ① توافق‌نامهٔ کاربر + سیاست حریم خصوصی، ② اعلام منابع باز اشخاص ثالث + سلب مسئولیت و ریسک‌ها، ③ راهنمای استفاده + مناطق مشمول و صلاحیت قضایی. هر سند باید **تا انتها اسکرول و جداگانه تأیید شود**؛ سپس گروه سنی انتخاب می‌شود (کاربران فعلی هم پس از به‌روزرسانی یک‌بار آن را می‌بینند).
- **بازهٔ زمانی برای افراد زیر سن قانونی**：زیر ۱۸ سال فقط جمعه، شنبه، یکشنبه و تعطیلات رسمی از ساعت **۲۰:۰۰ تا ۲۱:۰۰** می‌توانند بازی را اجرا کنند. تعطیلات ۲۰۲۶ روز‌به‌روز بر پایهٔ تقویم شورای دولتی چین (国办发明电〔2025〕7号) فهرست شده و روزهای جبرانی روز کاری شمرده می‌شوند.
- **سلب مسئولیت کامل نوشته شده**：از دست رفتن ذخیره‌ها، گرم شدن دستگاه، مسدودسازی توسط اشخاص ثالث، تعطیلی سرویس و ریسک‌های مشابه صریحاً اعلام می‌شوند.
- **همچنین**：کارت‌های صفحهٔ اصلی دیگر در حال بارگذاری گیر نمی‌کنند، جست‌وجوی وب هوش مصنوعی کار می‌کند، ورود داده به پوشهٔ نمونه (instance) انجام می‌شود و تعمیر خودکار پس از کرش حذف شده است.

> 🌍 **مناطق قابل استفاده در 28.1.0**：چین، ایالات متحده، کرهٔ جنوبی، ژاپن و روسیه. در سایر مناطق، نخستین اجرا صفحهٔ توضیح را نشان می‌دهد و برنامه به‌صورت ایمن بسته می‌شود.

## 🛠️ چه می‌کند

- **عامل هوش مصنوعی**：به‌طور پیش‌فرض DeepSeek — بازی، مادپک و ماد نصب می‌کند، تنظیمات را تغییر می‌دهد، لاگ می‌خواند و بازی را اجرا می‌کند
- **رندرکننده‌ها**：خودکار / MobileGlues / GL4ES / LTW (آزمایشی)
- **هستهٔ منابع**：جست‌وجو در Modrinth / CurseForge، حل وابستگی‌ها، دانلود، بررسی و نصب
- **علاقه‌مندی‌ها و بایگانی**：علاقه‌مندی آنلاین + بایگانی خصوصی با حذف تکراری بر پایهٔ SHA-256
- **محافظت از Fabric API**：Fabric API / Quilted Fabric API / Legacy Fabric API تنها از مسیر نصب افزوده می‌شوند — تکرار، جست‌وجو و حذفشان ممکن نیست
