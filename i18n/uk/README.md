# ZyNova

> 📌 **Current release: 28.4.0** · [Changelog](../../CHANGELOG.md) · [Releases](https://github.com/zzy89216-gif/ZyNova/releases/latest)

[![Platform](https://img.shields.io/badge/Platform-Android-brightgreen)](https://developer.android.com/)
[![Release](https://img.shields.io/badge/Release-28.4.0-purple)](https://github.com/zzy89216-gif/ZyNova/releases/tag/v28.4.0)

---

Лаунчер **Minecraft: Java Edition** для Android на коді ZalithLauncher2. Незалежний проєкт, не офіційна збірка.

Ідея проста: **менше натискань**. Спочатку лаунчер вирішує сам — і питає лише тоді, коли справді не може вирішити.

## 🚀 Швидкий старт

1. Завантажте APK з [Releases](https://github.com/zzy89216-gif/ZyNova/releases) і встановіть (Android 8.0+)
2. Перший запуск: три документи — прокрутити до кінця, позначити кожен, вибрати вікову групу
3. Вхід у Microsoft → вибір версії (або хай AI встановить) → запуск

## ✨ Останні зміни

**28.4.0** (найновіша): головні зміни:

- Оновлена головна: останні світи + повний список світів + власна стрічка.
- Сторінку «Персоналізація» прибрано, виправлено заголовок параметрів рендерера, оновлено посилання Discord.
- Видалення версії тепер показує визначений прогрес на весь екран.
- З центру головної прибрано старі картки світів, згруповані за версією (#100).
- Виправлено хибне визначення порожнього стану: коли всі версії приховані, завантаження більше не пропонується.
- Відкочено зміни 28.3.2, через які падали деякі екрани керування ресурсами (кеш списків / глобальний кеш значків / асинхронне завантаження плагінів); залишено лише повноекранне виправлення видалення версії.

> Зовнішній вигляд лишається як у 28.3.0 — без динамічного скла, заломлення та магнітних ефектів.

**28.3.0** (стабільна версія): головні зміни.

Цей стабільний випуск об'єднує весь вміст попередніх попередніх версій (їх видалено).

- **Кілька завантажень і встановлень одночасно**: версії гри, модпаки й ресурси можна запускати паралельно; у кожного завдання свій прогрес, швидкість і скасування. Повторне натискання на ту саму ціль тепер показує підказку, а не тишу.
- **Перетягування карток на головній стало стабільнішим**: довге натискання з перетягуванням більше не мерехтить і не спричиняє вильотів; під час швидкого перетягування картки міняються по одній, підтримується й горизонтальне перетягування.
- **Музичний плеєр доопрацьовано**: однойменні файли `.lrc` підхоплюються автоматично, текст пісні можна імпортувати прямо на сторінці; в уведомленні видно попередній і поточний рядки. У верхній панелі з'явився міні-плеєр (назва + відтворення/пауза + перемикання треку). Позиція й тривалість коректні й на паузі, а інтерфейс більше не виходить за межі екрана в альбомному режимі та на низьких екранах.
- **«Повернутися в гру» виправлено**: пункт зникає одразу після виходу з гри, а натискання за мить до цього більше не призводить до збою.
- **AI став сильнішим**: можна ставити кілька версій гри одночасно; додано інструменти керування музикою (загалом 53 інструменти).
- **Новий пункт «Мережева гра» в ігровому меню**: меню закривається, лаунчер одразу відкриває сторінку мережевої гри — гра продовжує працювати у фоні.

Повний список змін: [CHANGELOG.md](../../CHANGELOG.md).

## 🛠️ Що вміє

- **AI-агент**: типово DeepSeek — ставить гру, модпаки й моди, змінює налаштування, читає логи, запускає гру
- **Рендерери**: Авто / MobileGlues / Ironized Zink / GL4ES / LTW (експериментальний)
- **Ядро ресурсів**: пошук у Modrinth / CurseForge, розв'язання залежностей, завантаження, перевірка, встановлення
- **Обране й архів**: онлайн-обране + приватний архів із дедуплікацією SHA-256
- **Захист Fabric API**: додається лише процесом встановлення — продублювати, знайти пошуком чи видалити не вийде

## 🧩 Словник

- **Збірка (модпак)** — набір модів, який ставиться однією дією
- **Шейдери** — покращене освітлення й вода, вмикаються в налаштуваннях графіки
- **Інстанс** — окрема тека з версією, модами та налаштуваннями
