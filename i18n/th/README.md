## ✨ สิ่งใหม่ใน 28.1.0

- **ขั้นตอนข้อกำหนดตอนเปิดครั้งแรก**：เอกสารรวม 3 ฉบับ — ① EULA + นโยบายความเป็นส่วนตัว, ② ประกาศโอเพนซอร์สของบุคคลที่สาม + ข้อจำกัดความรับผิดและความเสี่ยง, ③ คู่มือการใช้งาน + พื้นที่ที่ใช้ได้และเขตอำนาจทางกฎหมาย ต้อง**เลื่อนจนสุดและติ๊กแยกทีละฉบับ**ก่อนไปต่อ จากนั้นจึงเลือกช่วงอายุ (ผู้ใช้เดิมก็เจอหนึ่งครั้งหลังอัปเดต)
- **ช่วงเวลาสำหรับผู้เยาว์**：อายุต่ำกว่า 18 ปี เปิดเกมได้เฉพาะวันศุกร์ เสาร์ อาทิตย์ และวันหยุดราชการ เวลา **20:00–21:00** โดยวันหยุดปี 2026 อ้างตามปฏิทินของคณะรัฐมนตรีจีน (国办发明电〔2025〕7号) และวันหยุดชดเชยที่ต้องทำงานถือเป็นวันทำงาน
- **ข้อจำกัดความรับผิดเขียนครบ**：ข้อมูลเซฟหาย เครื่องร้อน บัญชีถูกบุคคลที่สามแบน บริการปิดตัว ฯลฯ ระบุไว้ชัดเจน
- **นอกจากนี้**：การ์ดหน้าแรกไม่ค้างที่สถานะโหลดแล้ว, ค้นหาเว็บของ AI ใช้ได้, นำเข้าไปยังโฟลเดอร์อินสแตนซ์, ถอดระบบซ่อมแซมหลังแครชออกแล้ว

> 🌍 **พื้นที่ที่ใช้ได้ใน 28.1.0**：จีน สหรัฐอเมริกา เกาหลีใต้ ญี่ปุ่น และรัสเซีย พื้นที่อื่นเมื่อเปิดครั้งแรกจะแสดงหน้าระบุแล้วปิดแอปอย่างปลอดภัย

## 🛠️ ความสามารถ

- **เอเจนต์ AI**：ค่าเริ่มต้นคือ DeepSeek — ติดตั้งเกม ม็อดแพ็ก และม็อด เปลี่ยนการตั้งค่า อ่านบันทึก เปิดเกม
- **ตัวเรนเดอร์**：อัตโนมัติ / MobileGlues / GL4ES / LTW (ทดลอง)
- **แกนทรัพยากร**：ค้นหาใน Modrinth / CurseForge แก้ไข dependency ดาวน์โหลด ตรวจสอบ ติดตั้ง
- **รายการโปรดและคลังเก็บ**：รายการโปรดออนไลน์ + คลังส่วนตัว กันซ้ำด้วย SHA-256
- **การป้องกัน Fabric API**：Fabric API / Quilted Fabric API / Legacy Fabric API ถูกเพิ่มโดยขั้นตอนติดตั้ง — ติดตั้งซ้ำไม่ได้ ค้นไม่เจอ ลบไม่ได้

## 📦 ดาวน์โหลดและคอมไพล์เอง

- ดาวน์โหลด：<https://github.com/zzy89216-gif/ZyNova/releases> (ใช้เวอร์ชันล่าสุดเสมอ)
- คอมไพล์เอง：JDK 17 + Android SDK / NDK แล้วรัน `./gradlew ZalithLauncher:assembleRelease`
