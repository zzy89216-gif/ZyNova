# ZyNova

> 📌 **Current release: 28.4.0** · [Changelog](../../CHANGELOG.md) · [Releases](https://github.com/zzy89216-gif/ZyNova/releases/latest)

[![Platform](https://img.shields.io/badge/Platform-Android-brightgreen)](https://developer.android.com/)
[![Release](https://img.shields.io/badge/Release-28.4.0-purple)](https://github.com/zzy89216-gif/ZyNova/releases/tag/v28.4.0)

---

Android-നുള്ള **Minecraft: Java Edition** ലോഞ്ചർ. ZalithLauncher2-ന്റെ കോഡിൽ നിന്ന് സ്വതന്ത്രമായി വികസിപ്പിച്ച് പ്രസിദ്ധീകരിക്കുന്നു; ഇത് ഔദ്യോഗിക ബിൽഡ് അല്ല.

ആശയം ഒന്നേയുള്ളൂ: **കുറച്ച് സ്പർശനങ്ങൾ**. ഇരുപത് ക്രമീകരണങ്ങൾ നിരത്തിവയ്ക്കുന്നതിനു പകരം, ലോഞ്ചർ ആദ്യം തീരുമാനിക്കും — കഴിയാത്തപ്പോൾ മാത്രം ചോദിക്കും.

## ✨ സമീപകാല മാറ്റങ്ങൾ

**28.4.0** (ഏറ്റവും പുതിയത്): പ്രധാന മാറ്റങ്ങൾ:

- ഹോം പുതുക്കി: സമീപ ലോകങ്ങൾ + മുഴുവൻ ലോകപ്പട്ടിക + ഇഷ്ടാനുസൃത ഫീഡ്.
- «വ്യക്തിഗതമാക്കൽ» പേജ് ഒഴിവാക്കി, റെൻഡറർ വിശദാംശങ്ങളുടെ തലക്കെട്ട് ശരിയാക്കി, Discord ലിങ്ക് പുതുക്കി.
- പതിപ്പ് ഡിലീറ്റ് ഇപ്പോൾ പൂർണ സ്ക്രീനിൽ കൃത്യമായ പുരോഗതി കാണിക്കുന്നു.
- ഹോമിന്റെ നടുവിലെ പഴയ ഇൻസ്റ്റൻസ് അനുസരിച്ച് ഗ്രൂപ്പ് ചെയ്ത ലോക കാർഡുകൾ ഒഴിവാക്കി (#100).
- ഹോമിന്റെ ശൂന്യാവസ്ഥ തെറ്റായി കണ്ടെത്തുന്നത് ശരിയാക്കി: എല്ലാ പതിപ്പുകളും മറച്ചിരിക്കുമ്പോൾ ഇനി ഡൗൺലോഡ് നിർദ്ദേശിക്കില്ല.
- 28.3.2-ൽ ചില റിസോഴ്സ് മാനേജ്മെന്റ് സ്ക്രീനുകൾ ക്രാഷ് ചെയ്യിച്ച മാറ്റങ്ങൾ പിൻവലിച്ചു (ലിസ്റ്റ് കാഷെ / ഐക്കൺ ഗ്ലോബൽ കാഷെ / പ്ലഗിൻ അസിങ്ക് ലോഡിംഗ്); പതിപ്പ് ഡിലീറ്റിന്റെ പൂർണ സ്ക്രീൻ പരിഹാരം മാത്രം നിലനിർത്തി.

> രൂപം 28.3.0 പോലെ തന്നെ — ഡൈനാമിക് ഗ്ലാസ്, റിഫ്രാക്ഷൻ, കാന്തിക ഇഫക്ടുകൾ ഇല്ല.

**28.3.0** (സ്ഥിരമായ പതിപ്പ്): പ്രധാന മാറ്റങ്ങൾ.

ഈ സ്ഥിരമായ പതിപ്പ് മുൻ പ്രീ-റിലീസുകളുടെ മുഴുവൻ ഉള്ളടക്കവും ഉൾപ്പെടുത്തുന്നു (ആ പതിപ്പുകൾ നീക്കം ചെയ്തു).

- **ഒരേസമയം ഒന്നിലധികം ഡൗൺലോഡും ഇൻസ്റ്റാളും**: ഗെയിം പതിപ്പുകൾ, മോഡ്പാക്കുകൾ, റിസോഴ്സുകൾ ഒരുമിച്ച് തുടങ്ങാം; ഓരോ ജോലിക്കും സ്വന്തം പ്രോഗ്രസ്, വേഗത, റദ്ദാക്കൽ ഉണ്ട്. അതേ ഇനത്തിൽ വീണ്ടും അമർത്തിയാൽ ഇപ്പോൾ ഒരു അറിയിപ്പ് വരും, ഒന്നും സംഭവിക്കാതെ പോകില്ല.
- **ഹോം സ്ക്രീനിലെ കാർഡുകൾ പുനഃക്രമീകരിക്കൽ കൂടുതൽ സ്ഥിരതയുള്ളത്**: ദീർഘനേരം അമർത്തി വലിച്ചിടുമ്പോൾ ഇനി വെട്ടിത്തിളങ്ങുന്നില്ല, ആപ്പ് അടയുന്നുമില്ല; വേഗത്തിൽ വലിച്ചിട്ടാലും ഓരോ കാർഡായി മാറും, തിരശ്ചീനമായി വലിക്കാനും കഴിയും.
- **മ്യൂസിക് പ്ലേയർ മെച്ചപ്പെടുത്തി**: അതേ പേരുള്ള `.lrc` ലിറിക്സ് സ്വയം ലോഡ് ചെയ്യും, പേജിൽ നിന്ന് ലിറിക്സ് ഇംപോർട്ട് ചെയ്യാം; അറിയിപ്പിൽ മുൻവരിയും നിലവിലെ വരിയും കാണാം. മുകളിലെ ബാറിൽ മിനി പ്ലേയർ (പാട്ടിന്റെ പേര് + പ്ലേ/പോസ് + ട്രാക്ക് മാറ്റൽ) വന്നു. താൽക്കാലികമായി നിർത്തിയാലും സ്ഥാനവും ദൈർഘ്യവും ശരിയായി കാണിക്കും; ലാൻഡ്സ്കേപ്പിലും താഴ്ന്ന സ്ക്രീനുകളിലും ലേഔട്ട് ഇനി പുറത്തേക്ക് കവിയില്ല.
- **«ഗെയിമിലേക്ക് മടങ്ങുക» ശരിയാക്കി**: ഗെയിം അടയ്ക്കുമ്പോൾ തന്നെ എൻട്രി അപ്രത്യക്ഷമാകും; അതിനു തൊട്ടുമുൻപ് അമർത്തിയാലും ഇനി ക്രാഷ് ഉണ്ടാകില്ല.
- **AI കൂടുതൽ ശക്തം**: ഒരേസമയം ഒന്നിലധികം ഗെയിം പതിപ്പുകൾ ഇൻസ്റ്റാൾ ചെയ്യാം; സംഗീത നിയന്ത്രണത്തിനുള്ള ടൂളുകൾ ചേർത്തു (ആകെ 53 ടൂളുകൾ).
- **ഗെയിമിനുള്ളിലെ മെനുവിൽ പുതിയ «മൾട്ടിപ്ലെയർ»**: മെനു അടയുന്നു, ലോഞ്ചർ നേരിട്ട് മൾട്ടിപ്ലെയർ പേജ് തുറക്കുന്നു; ഗെയിം അടയ്ക്കുന്നില്ല, പിന്നിൽ തുടരും.

എല്ലാ മാറ്റങ്ങളും: [CHANGELOG.md](../../CHANGELOG.md).
