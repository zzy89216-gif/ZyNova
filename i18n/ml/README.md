Android-നുള്ള **Minecraft: Java Edition** ലോഞ്ചർ. ZalithLauncher2-ന്റെ കോഡിൽ നിന്ന് സ്വതന്ത്രമായി പരിപാലിച്ച് പ്രസിദ്ധീകരിക്കുന്നു; ഇത് ഔദ്യോഗിക ബിൽഡ് അല്ല.

ലക്ഷ്യം: **കുറച്ച് സ്പർശനങ്ങൾ**. യാന്ത്രികമാക്കാവുന്നതെല്ലാം — ഗെയിം ഇൻസ്റ്റാൾ, മോഡുകളും മോഡ്പാക്കുകളും കണ്ടെത്തൽ, ക്രമീകരണ മാറ്റം, ലോഗ് വായന — AI ഏജന്റ് ഏറ്റെടുക്കുന്നു.

## ✨ 28.1.0-ലെ പുതിയത്

- **ആദ്യ തുടക്കത്തിലെ അനുസരണ നടപടിക്രമം**：മൂന്ന് രേഖകൾ — ① EULA + സ്വകാര്യതാ നയം, ② മൂന്നാം കക്ഷി ഓപ്പൺ സോഴ്സ് അറിയിപ്പ് + ഉത്തരവാദിത്വ നിരാകരണവും അപകടസാധ്യതകളും, ③ ഉപയോഗ പരിശീലനം + ബാധകമായ പ്രദേശങ്ങളും നിയമ അധികാരവും. ഓരോ രേഖയും **അവസാനം വരെ സ്ക്രോൾ ചെയ്ത് പ്രത്യേകം ടിക്ക് ചെയ്യണം**; ശേഷം പ്രായ വിഭാഗം തിരഞ്ഞെടുക്കണം (നിലവിലുള്ള ഉപയോക്താക്കളും അപ്ഡേറ്റിന് ശേഷം ഒരിക്കൽ ഇത് കാണും).
- **പ്രായപൂർത്തിയാകാത്തവർക്കുള്ള സമയപരിധി**：18 വയസ്സിൽ താഴെയുള്ളവർക്ക് വെള്ളി, ശനി, ഞായർ, ഔദ്യോഗിക അവധിദിനങ്ങളിൽ **20:00–21:00** മാത്രം ഗെയിം തുടങ്ങാം; 2026-ലെ അവധികൾ ചൈനീസ് സ്റ്റേറ്റ് കൗൺസിൽ കലണ്ടർ (国办发明电〔2025〕7号) അനുസരിച്ച് ദിവസം തിരിച്ച് നൽകിയിരിക്കുന്നു; പകരം ജോലിദിനങ്ങൾ ജോലിദിനമായി കണക്കാക്കും.
- **ഉത്തരവാദിത്വ നിരാകരണം പൂർണമായി**：സേവ് നഷ്ടം, ഉപകരണം ചൂടാകൽ, മൂന്നാം കക്ഷി ബാൻ, സേവനം നിർത്തൽ തുടങ്ങിയ അപകടസാധ്യതകൾ വ്യക്തമായി അറിയിക്കുന്നു.
- **കൂടാതെ**：ഹോം കാർഡുകൾ ലോഡിംഗിൽ കുടുങ്ങുന്നില്ല, AI വെബ് തിരച്ചിൽ പ്രവർത്തിക്കുന്നു, ഇംപോർട്ട് instance ഫോൾഡറിലേക്ക് പോകുന്നു, ക്രാഷിന് ശേഷമുള്ള യാന്ത്രിക അറ്റകുറ്റപ്പണി നീക്കം ചെയ്തു.

> 🌍 **28.1.0-ൽ ലഭ്യമായ പ്രദേശങ്ങൾ**：ചൈന, യുഎസ്, ദക്ഷിണ കൊറിയ, ജപ്പാൻ, റഷ്യ. മറ്റ് പ്രദേശങ്ങളിൽ ആദ്യ തുടക്കത്തിൽ വിവര പേജ് കാണിച്ച് ആപ്പ് സുരക്ഷിതമായി അടയ്ക്കും.

## 🛠️ എന്തു ചെയ്യും

- **AI ഏജന്റ്**：സ്ഥിരസ്ഥിതി DeepSeek — ഗെയിം, മോഡ്പാക്കുകൾ, മോഡുകൾ ഇൻസ്റ്റാൾ ചെയ്യുന്നു, ക്രമീകരണങ്ങൾ മാറ്റുന്നു, ലോഗുകൾ വായിക്കുന്നു, ഗെയിം തുടങ്ങുന്നു
- **റെൻഡററുകൾ**：ഓട്ടോ / MobileGlues / GL4ES / LTW (പരീക്ഷണാത്മകം)
- **റിസോഴ്സ് കോർ**：Modrinth / CurseForge തിരച്ചിൽ, ആശ്രിതത്വ പരിഹാരം, ഡൗൺലോഡ്, പരിശോധന, ഇൻസ്റ്റാൾ
- **പ്രിയപ്പെട്ടവയും ആർക്കൈവും**：ഓൺലൈൻ പ്രിയപ്പെട്ടവ + സ്വകാര്യ ആർക്കൈവ്, SHA-256 ഉപയോഗിച്ച് ആവർത്തന ഒഴിവാക്കൽ
- **Fabric API സംരക്ഷണം**：Fabric API / Quilted Fabric API / Legacy Fabric API ഇൻസ്റ്റാൾ ഫ്ലോ വഴി മാത്രം ചേർക്കുന്നു — ആവർത്തിക്കാനോ തിരയാനോ ഒഴിവാക്കാനോ കഴിയില്ല
