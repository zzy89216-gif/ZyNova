Android 上的 Minecraft: Java Edition 启动器，基于 ZalithLauncher2 源码自行维护发布，GPL-3.0。
目标是「少点几下」：玩家的操作尽量交给 AI 和自动化流程。

- GitHub：<https://github.com/zzy89216-gif/ZyNova>
- Issues：<https://github.com/zzy89216-gif/ZyNova/issues>
- Discord：<https://discord.gg/QwPpZQHrTa>

## ✨ 28.0.6 更新要点

- **修掉 P0 崩溃**：`web_search` 不再在主线程发网络请求（`NetworkOnMainThreadException`），三个联网工具全部走 IO 线程
- **AI 能直接做 Word / PPT**：`create_docx` / `create_pptx`，手写 OOXML，不引 Apache POI（包体不涨），默认存 `Download`
- **联网失败有兜底**：搜索失败会自动改用 `fetch_webpage` 抓结果页，不再中断
- **路径与配置修正**：能列出实例的父目录（`Minecraft`、`versions`）；图形模式/粒子/FOV 显示游戏真实取值
- **杂项**：Photo Picker 不再刷授权报错、不再产生空壳日志、「JVM 上限」改为启动器进程堆上限

## 🛠️ 能做什么

- **AI Agent**：默认 DeepSeek，能装游戏 / 装整合包 / 装模组 / 改设置 / 读日志 / 启动游戏
- **渲染器**：自动 / MobileGlues / GL4ES / LTW（实验性）
- **资源核心**：Modrinth / CurseForge 搜索 → 依赖解析 → 下载 → 校验 → 安装
- **收藏与归档**：在线收藏 + 私有目录归档，SHA-256 去重
- **前置 API 防呆**：Fabric / Quilted / Legacy Fabric API 由安装流程自动加入，不可重复安装、搜不到、删不掉

## 📦 下载与构建
