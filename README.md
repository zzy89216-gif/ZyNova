# ZyNova

ZyNova 是一个基于 ZalithLauncher2 开源代码开发的 Minecraft: Java Edition Android 启动器。

本项目在上游项目的代码基础上进行了大量修改、重构、功能开发与界面调整，并由 ZyNova 项目维护者独立进行后续开发与维护。

ZyNova 并非 ZalithLauncher2 官方版本，而是一个基于其开源代码进行开发的非官方修改项目。

---

## 项目简介

ZyNova 是一个面向 Android 平台的 Minecraft: Java Edition 启动器项目。

本项目基于 ZalithLauncher2 的开源代码进行开发，并根据实际需求对原有工程进行了进一步修改。

目前项目涉及的开发内容包括：

- Android 启动器功能调整
- 用户界面与交互设计调整
- 启动器功能重构
- Minecraft 启动相关功能修改
- 游戏实例管理相关功能
- 安装与管理功能调整
- Android 平台相关功能调整
- 原有代码结构重构
- 新功能开发
- 性能与兼容性调整
- 其他与启动器运行体验相关的修改

ZyNova 将根据实际开发情况持续更新。
