# Instance settings

Instance page → Version settings:

- Java runtime
- Memory (min / max)
- Renderer (can follow global)
- Resolution scale / fullscreen
- JVM arguments
- Custom game directory (defaults to the public `/ZyNova/.Minecraft`; you can point it at another
  folder, for example `/storage/emulated/0/Minecraft`)

Changes apply on the next launch; no need to recreate the instance.
