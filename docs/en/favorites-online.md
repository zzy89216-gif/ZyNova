# Online favorites

- Tap ♥ on a resource card or project page to favorite it.
- View them under Favorites → Online; remote info can be refreshed.
- Cards look the same as in the resource download list: icon, title, author, description, download / follow counts, loader and category labels, and tapping a card opens its details.
- To unfavorite, tap the ♥ at the card's right edge; the button is intentionally small so the title and description keep their space.
- Stores project IDs and cache only; installing needs a network connection.
