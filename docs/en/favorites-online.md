# Online favorites

- Tap ♥ on a resource card or project page to favorite it.
- View them under Favorites → Online; remote info can be refreshed.
- Cards are **simplified**: icon, title, author and type only — no description and no download counts. Tap a card for details.
- Two buttons on the right: **the big one downloads** (one tap installs into an instance, required dependencies included), **the small ♥ unfavorites**.
- Stores project IDs and cache only; installing needs a network connection.
