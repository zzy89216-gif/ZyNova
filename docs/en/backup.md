# Backing up an instance

- Instances live in public storage under `/storage/emulated/0/ZyNova/.Minecraft/`; copying the whole instance
  folder is the safest option (it includes mods, config and saves).
- Worlds can also be exported separately from world management.
- Uninstalling does **not** remove instances and worlds under `/ZyNova`, but Java runtimes, the favourites
  archive, accounts and settings are deleted. To move phones or before wiping, copy `.Minecraft` somewhere else.
- Settings can be exported/imported from the settings screen; accounts need signing in again
  (tokens are never written to public storage).
