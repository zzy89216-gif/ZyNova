# Updating the launcher

- In-app updates compare `versionCode`; replacing an APK with the same version code will not prompt users.
- Overwriting keeps instances, accounts and settings.
- Upgrading from an older build runs a one-time **full-screen migration** into `/ZyNova/.Minecraft`
  when game data is still in private storage; you tap Next when it finishes.
- Back up important worlds before a major update (no need to uninstall; just install over the top).
