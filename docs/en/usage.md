# Daily usage

## Interface

- The top bar is a centered liquid-glass capsule:
  **Home / AI / Multiplayer / Downloads / Files / Personalization / Settings**.
- The title stays in the top-left corner; a back button appears on sub-pages.
- While a download is running, a small ring appears at the right end of the capsule —
  tap it to open the task panel.
- All appearance options live in **Settings → General**; the top-bar
  **Personalization** entry is only a shortcut to them.

## Game

Top capsule → Downloads → Game → version → loader → install. Progress is in the top bar; tap for details.

## Instances

Open an instance card to edit Java, memory, renderer, resolution and JVM arguments.
Mod management can enable, disable or delete mods. Fabric API is managed automatically.

## Logs and export

Run logs live on the version overview page. Export supports Modrinth only.

## Favorites

Tap ♥ on a resource card or project page. See `favorites.md`.

## Back key and ESC in game

- **The back key only toggles the launcher menu**: inside the game it opens the control menu (mouse / gamepad / gestures / gyroscope, logs, exit), and never jumps around inside the game;
- **To reach Minecraft's own pause menu**: open the launcher menu → tap "Send ESC (game pause menu)";
- The menu also has "Back to launcher", which **does not stop the game** — you return to the same session;
- Changing controls, checking logs or switching input methods all happen in this menu — no need to quit the game.
