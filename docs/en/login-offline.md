# Offline accounts

## How to add one

1. Accounts page → add account → **Offline**.
2. Enter a username (that is the in-game display name) → save.
3. Go back home, pick the instance and start it.

## What it can do

- Single-player;
- LAN play;
- Offline-mode servers (`online-mode=false`).

## What it cannot do

- **It cannot join online-mode servers** (`online-mode=true`): the server rejects it — this is not a launcher problem;
- It cannot be used for purchases, skin syncing, Realms or anything that needs a genuine account.

## Notes

- Offline accounts **do not verify a password**: anyone typing the same name gets the same identity.
- Do not use an offline account on an online-mode server; you will usually be kicked, and it may break server rules.
- Offline and Microsoft accounts are separate records; switching accounts does not touch your saves or instances.
- If the server has a whitelist, add this username to it first, otherwise you cannot join.
