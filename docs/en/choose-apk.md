# Which APK to download

| File | Devices | Notes |
|---|---|---|
| `ZyNova-<version>.apk` | All Android devices | Universal, four ABIs |
| `ZyNova-<version>-arm64-v8a.apk` | arm64 phones | Smaller, 64-bit libraries only |

Pick the universal build unless you know you are on arm64. LTW only appears on arm64.
