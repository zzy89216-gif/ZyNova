# Installing or importing worlds

- Download → Worlds → install to an instance; or
- copy the world folder into the instance `saves/` directory.

Find it under Singleplayer. Large worlds take longer on first load.

## Getting there from the home screen

- The **Recently played** row at the top of the home screen lists the worlds you played last (up to four, aggregated across instances). Tap a world to launch it; the fifth card, **View all**, opens the **All worlds** list.
- The All worlds page collects every local world from all instances:
  - the search box filters by world name / save folder name / instance name;
  - sorting by **Last played** or **Name**, ascending or descending;
  - two filter dropdowns narrow the list by **instance** and **game version**;
  - tapping a row launches the game; the row shows the instance, game version and last-played time ("Never played" if so).
- The list only scans recently used instances and recently modified saves, so opening and leaving it stays fast.
