# Installing modpacks

1. Download → Modpacks.
2. Pick a Modrinth or CurseForge project and version.
3. Installation creates a new instance and resolves dependencies.
4. The first launch may download more libraries.

Modpacks are not regular resources; do not use the resource install path.

## Importing a local modpack

1. Download → Modpacks, then the import button at the top right, and pick an archive
   (.mrpack, .zip, .curseforge and so on).
2. The launcher unpacks it, asks for an instance name, then starts importing.
3. Importing runs as a **background task**: you can leave the page or switch apps, and the progress
   is still in the task panel when you come back.
4. To stop it, cancel from the task panel; no half-finished instance is left behind.

Supported formats include Modrinth (.mrpack), CurseForge, MultiMC / Prism and HMCL exports.
Unsupported archives tell you why up front instead of failing halfway through.
