# Uninstalling

- **Kept**: public `/ZyNova/.Minecraft` (instances, worlds, mods, resource packs, shaders, skin cache) and `/ZyNova/logs`.
- **Removed**: private app storage, which holds Java runtimes, the favourites archive, control layouts,
  accounts, settings and the MobileGlues config.

Export accounts and settings from the app first if you need them. Game data survives an uninstall,
but copying `.Minecraft` elsewhere is still the safe move before switching devices.
