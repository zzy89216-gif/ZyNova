# Troubleshooting

## First: get the log

- Game crash: Share Logs on the crash screen.
- Launcher crash: settings → about / log entry.
- Run log: version overview → Run log.

## Crash analysis

27.9.0 adds a "What to do next" card for missing dependencies, mod load failures, duplicate mods, Java, memory, renderer, corrupt files and missing classes.

## Common checks

1. Switch renderer.
2. Check Java version.
3. Remove recently added mods/shaders.
4. Read the first `Caused by`.
5. Check network for download issues.

## When reporting

Include device, Android version, launcher version, game version + loader, steps and a log link.
