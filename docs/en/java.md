# Java version

| Minecraft | Recommended Java |
|---|---|
| 1.16 and older | 8 / 11 |
| 1.17 – 1.20.4 | 17 |
| 1.20.5+ / 26.x | 21 |

`UnsupportedClassVersionError` means Java is too old. Change it in instance settings.
The launcher can download runtimes, or you can pick one under Java management.
