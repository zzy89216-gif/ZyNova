# MobileGlues

- Desktop OpenGL translated onto the device GLES stack.
- Settings → Renderer → MobileGlues:
  - OpenGL version (default 4.0)
  - ANGLE backend (off by default)
  - multidraw order (only for rendering glitches)
- Config lives in `mobileglues/config.json` inside private storage; `/sdcard/MG` is untouched.
