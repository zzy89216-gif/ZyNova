# Glossary

- **Instance**: one game version plus mods and config.
- **Loader**: Fabric / Forge / NeoForge / Quilt.
- **Dependency**: another mod required by a mod.
- **Modpack**: a complete set of mods and config.
- **Renderer**: layer translating desktop GL to mobile.
- **Mapping**: obfuscation map used to read crash stacks.
