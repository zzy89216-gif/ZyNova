# 离线账号

## 怎么添加

1. 账号页 → 添加账号 → **离线**。
2. 填一个用户名（就是游戏里的显示名）→ 保存。
3. 回首页选中实例即可启动。

## 能做什么

- 单机游戏；
- 局域网联机；
- 离线模式服务器（`online-mode=false`）。

## 不能做什么

- **进不了正版验证服务器**（`online-mode=true`）：服务器会拒绝，这不是启动器的问题；
- 不能用于购买、皮肤同步、Realms 等需要正版身份的功能。

## 注意

- 离线账号**不验证密码**：任何人输入同一个名字，都会得到同一个身份。
- 不要拿离线账号去登正版服务器，大概率被踢，也可能违反服务器规则。
- 离线账号与正版账号是两条独立记录，切换账号不会影响存档和实例。
- 服务器开了白名单时，要先把这个用户名加进白名单，否则进不去。
