# 选哪个 APK

只提供一个安装包，不用再挑：

| 文件 | 适用 | 说明 |
|---|---|---|
| `ZyNova-<版本>.apk` | 所有设备 | 通用版，包含全部 ABI（arm64-v8a / armeabi-v7a / x86 / x86_64） |

以前的 `-arm64-v8a` 体积优化版已经取消：它并没有多出功能，只是省一点体积，
却让人每次都要判断自己的机型。现在统一只发通用版。

- 渲染器 LTW-Turbo 的库本身只提供 arm64，**在 arm64 手机上通用版照样能用**；
  其他架构的设备不会看到这个选项。
- 发版同时只附带一个代码混淆映射 `mapping.universal.zip`，用于崩溃堆栈还原，普通用户不用下载。
