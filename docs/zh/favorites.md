# 收藏与本地归档

## 两套东西，不要混

| | 在线收藏 | 本地归档 |
|---|---|---|
| 存什么 | 平台项目 ID + 缓存信息 | 文件副本（SHA-256 去重） |
| 在哪 | MMKV | 应用私有目录 `files/favorites/` |
| 断网 | 只能看缓存，不能安装 | 可用 |
| 删除 | 只删收藏记录 | 只删副本，不影响在线收藏 |

## 怎么收藏

- 资源搜索结果卡片右侧 ♥；
- 项目详情页右上角 ♥；
- 再点一次取消收藏。

## 本地归档

- 入口：收藏页 →「本地归档」→ 导入。
- 通过系统文件选择器选文件；复制进私有目录，原文件不动。
- 支持识别：存档、整合包、材质包、数据包、光影、模组。
- 删除归档只删副本；卸载应用会清空整个私有目录。

## 安装

- 在线收藏：详情 → 安装到实例；会自动解析前置。
- 本地归档：安装到实例；无法在线识别的文件会直接复制，前置需手动补。
- **从「版本设置 → 资源管理」进入时**，收藏页带着该实例的上下文：卡片右侧的下载按钮点一下就直接下载并装进这个实例，必需前置一起装好；从主页资源中心进入则保持纯浏览。

## 卡片外观

收藏页的卡片和资源下载列表（模组、资源包等）是同一种样式：左侧图标，右侧标题、作者、描述、下载量 / 收藏量，底部是加载器与类别标签。
