# 安装 / 导入存档

- 「下载」→「存档」→ 安装到实例；或
- 文件管理器把存档文件夹放到实例的 `saves/`。

导入后进游戏「单人游戏」查看；地图过大时首次加载会慢。

## 从主页进世界

- 主页顶部「最近游玩的」会显示最近玩过的世界（最多 4 个，跨实例汇总）；点世界卡片直接进游戏，点第 5 张「查看全部」进入**全部世界**列表页。
- 全部世界页把**所有实例下的本地世界**收在一起：
  - 搜索框按世界名 / 存档文件夹名 / 实例名过滤；
  - 排序支持「最后游玩」「名称」，可切换升序 / 降序；
  - 两个筛选下拉分别按**实例**和**游戏版本**收窄结果；
  - 点任意一行直接进游戏，行上会写明实例、游戏版本和最后游玩时间（没玩过显示「从未游玩」）。
- 列表只扫描最近使用的实例与最近改动过的存档，不会全盘扫描，进出页面都很快。
