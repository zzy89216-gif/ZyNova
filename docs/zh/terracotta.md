# 陶瓦联机（P2P）

ZyNova 有两种联机方式，陶瓦是其中「不开端口」的那种：

| 方式 | 原理 | 需要 | 适合 |
|---|---|---|---|
| 陶瓦联机 | P2P 组网（EasyTier），双方进入同一虚拟局域网 | 双方都装 ZyNova | 熟人开黑、不想开端口 |
| [樱花内网穿透](https://github.com/zzy89216-gif/ZyNova/blob/main/docs/zh/frp.md) | 把本机端口映射到公网节点（frp） | 一个樱花账号 + 访问密钥 | 对方用电脑客户端、或不想装陶瓦 |

入口：**多人联机**。

## 前提

1. 双方都安装 ZyNova（版本不必完全一致，但建议同版本）；
2. 第一次使用会要求确认「用户须知」并申请 **通知权限**（联机状态靠常驻通知保活）；
3. 首次建房 / 加房会申请 **VPN 权限**（EasyTier 通过系统 VPN 接口组网，这是正常现象）。

> 联机核心（`libterracotta.so`）与 VPN 服务是上游组件，本项目不改动其协议。

## 房主：创建房间

1. 进入游戏存档，按 `Esc` → **对局域网开放** → 记下聊天栏里的端口；
2. 回到启动器（或游戏内悬浮菜单）→ 多人联机 → **创建房间**；
3. 等待节点扫描完成（首次会拉取节点列表并缓存 **10 分钟**，期间重复建房不会重复请求）；
4. 成功后页面会显示**房间码**，点一下即可复制，发给朋友。

房间码长这样：

```
U/XXXX-XXXX-XXXX-XXXX
```

- 字符表是 34 进制（去掉了容易看错的 `I` / `O`）；
- 生成时数字会被 `value -= value mod 7` 处理，因此「能被 7 整除」可用于校验；
- **不要手抄错**：`I` 与 `1`、`O` 与 `0` 在字体里很像，直接复制粘贴最稳。

## 房客：加入房间

1. 多人联机 → **加入房间**；
2. 粘贴房主给的房间码 → 确认；
3. 等待进入虚拟局域网，成功后页面会给出**连接地址**，点一下复制；
4. 打开游戏 → 多人游戏 → 直接连接 → 粘贴地址。

### 粘贴格式会自动整理

房客输入框现在会自动归一化，下面这些写法都能识别：

| 你粘贴的 | 实际使用 |
|---|---|
| `u/abcd-efgh-ijkl-mnop` | `U/ABCD-EFGH-IJKL-MNOP` |
| `U/ABCD EFGH IJKL MNOP`（带空格） | 自动去掉空格 |
| `【U/ABCD-EFGH-IJKL-MNOP】` | 自动去掉括号 |
| 全角字符、`I`→`1`、`O`→`0` | 自动纠正 |
| `abcd...`（没有 `U/` 前缀） | 自动补全格式 |

整理后输入框下方会提示「已自动整理为 `U/XXXX-XXXX-XXXX-XXXX`」，
如果提示「房间码有误」，说明这串字符本身不合法（多半是复制时漏了字符）。

## 失败时怎么办

| 现象 | 处理 |
|---|---|
| 建房失败，提示「请确认游戏内已对局域网开放」 | 回到游戏里重新「对局域网开放」，注意聊天栏里的端口，然后重试 |
| 加房失败 | 确认房间码没过期、房主还在房间里；换一个网络（Wi-Fi ↔ 流量）再试 |
| 一直卡在扫描节点 | 稍等重试；节点列表缓存 10 分钟，极端情况下杀掉应用重开会重新拉取 |
| 进了虚拟网但游戏连不上 | 确认房主游戏没暂停（单机暂停时服务端不响应）、双方版本与模组一致 |
| 想用自己的 EasyTier 节点 | 多人联机 → 启用 → 自定义服务器节点，填入节点地址 |

日志：多人联机 → **分享联机核心日志**，可以在反馈时附上（注意里面有网络地址）。

## 和樱花内网穿透的区别

- 陶瓦：**双方都要装 ZyNova**，走 P2P，不开端口、不需要账号；
- 樱花：**只要房主有樱花账号**，把端口映射到公网，对方用原版客户端也能连。

两者互不影响，可以按场景选。
