# 陶瓦联机（P2P）

不开端口、不需要服务器，**双方都要装 ZyNova**。入口：顶部「多人联机」（屏幕中下方的悬浮菜单里选「陶瓦」）。

## 先做好准备（房主和房客都要做）

1. 打开「多人联机」页，把 **启用多人联机** 开关打开，读完用户须知点确认；
2. 允许通知：联机状态显示在通知栏，通知被禁时后台更容易被系统杀掉；
3. **先开开关、再启动游戏**——这个开关是启动游戏时读取的，进游戏以后改没有用；
4. 第一次点「房主 / 房客」会请求 **VPN 权限**（EasyTier 要建虚拟网卡），必须允许，否则连不上。

## 房主

1. 进入一个**单人存档**，按 `Esc` →「对局域网开放」→ 记住端口（默认 25565，改了就记下来）
   → 点「创建局域网世界」。**没做这步，点房主会一直卡在扫描**；
2. 点游戏里的**悬浮菜单球** →「菜单」→「联机菜单」→「我想当房主」
   （没开「启用多人联机」时菜单里不会有这一项）；
3. 状态会依次走过：正在扫描局域网世界 → 正在启动房间 → 已启动房间；
4. 成功后显示邀请码 `U/XXXX-XXXX-XXXX-XXXX`，**已自动复制到剪贴板**；没复制上就点「复制邀请码」；
5. 发给朋友，让他在联机菜单里选「我想当房客」输入。

> 玩的时候**别退出存档**：退出存档房间会自动关闭。要关房间按「退出」，房间一关邀请码立刻作废。

## 房客

1. 启动游戏，停在主界面就行，不用进存档；
2. 悬浮菜单球 →「菜单」→「联机菜单」→「我想当房客」；
3. 粘贴房主给的邀请码后点确定：空格、连字符、`U/` 前缀会自动整理，输入框下面会显示识别到的类型
   （陶瓦 / PCL CE / Scaffolding）；
4. 等「正在加入房间」走完，期间会按双方网络给出连接成功率预估，**仅供参考**；
5. 出现「已加入房间」才算成功；然后回游戏主界面 →「多人游戏」→ 刷新列表 → 双击「陶瓦联机大厅」；
6. 列表里没有就用联机菜单里的「复制备用联机地址」，在「多人游戏 → 直接连接」里粘贴。

**版本和模组必须和房主一致**（游戏版本、加载器、模组），否则能连上也进不去世界。
离线账号可以联机；但「备用联机地址」方式不支持离线账号，优先走大厅列表。

## 房间码

形如 `U/XXXX-XXXX-XXXX-XXXX`（34 进制、去掉易混的 `I` / `O`）。
输入框会自动整理格式：全角、空格、连字符、`【】`、缺 `U/` 前缀、`I`→`1`、`O`→`0` 都能识别，
整理后提示「已自动整理为 …」。提示「邀请码错误」说明这串字符本身不合法。

## 出问题时

| 现象 | 处理 |
|---|---|
| 点房主一直卡在扫描 | 回游戏确认已经「对局域网开放」并创建了局域网世界，再点一次 |
| 点房主直接失败 | 同上；另外确认弹过 VPN 权限并允许了 |
| 加房失败 / 提示邀请码错误 | 确认邀请码没写错、房主房间还在（房间一关就作废），换 Wi-Fi / 流量再试 |
| 已加入房间但列表里没有大厅 | 用「复制备用联机地址」走「直接连接」；确认双方版本与模组一致 |
| 提示「房间已关闭」 | 房主退出了存档或主动关了房间，让他重开再发新邀请码 |
| 连上就掉 / 很卡 | 双方都在国内网络、别双开加速器；房主游戏别暂停 |
| 想用自己的节点 | 联机页 →「自定义 EasyTier 服务器节点」（留空用默认） |

日志：联机菜单里点「查看日志」；要反馈问题就回「联机」页点「分享联机核心日志」（注意含网络地址）。

## 和其他客户端互通

支持与 FCL、HMCL、PCL CE（陶瓦）等 Scaffolding 客户端互通，对面不一定非要用本启动器。

与[樱花内网穿透](https://github.com/zzy89216-gif/ZyNova/blob/main/docs/zh/frp.md)的区别：陶瓦双方都要装 ZyNova、走 P2P；
樱花只要房主有账号，对方用原版客户端也能连。
