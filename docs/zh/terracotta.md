# 陶瓦联机（P2P）

不开端口的联机方式，**双方都要装 ZyNova**。入口：多人联机。

## 房主

1. 游戏里 `Esc` → **对局域网开放**，记下聊天栏的端口；
2. 启动器 → 多人联机 → 创建房间，等节点扫描完成；
3. 成功后显示房间码，点一下复制发给朋友。

## 房客

1. 多人联机 → 加入房间 → 粘贴房间码；
2. 成功后复制连接地址，游戏里「直接连接」粘贴即可。

房间码形如 `U/XXXX-XXXX-XXXX-XXXX`（34 进制、去掉易混的 `I`/`O`）。
输入框会自动整理格式：全角、空格、连字符、`【】`、缺 `U/` 前缀、`I`→`1`、`O`→`0` 都能识别，
整理后会提示「已自动整理为 …」。提示「房间码有误」说明这串字符本身不合法。

## 出问题时

| 现象 | 处理 |
|---|---|
| 建房失败 | 回游戏重新「对局域网开放」，确认端口后再试 |
| 加房失败 | 确认房间码新鲜、房主还在房间；换 Wi-Fi / 流量再试 |
| 卡在节点扫描 | 稍等重试；节点列表缓存 10 分钟，重启应用会重新拉取 |
| 进了虚拟网但连不上 | 房主游戏不要暂停，双方版本与模组保持一致 |
| 想用自己的节点 | 多人联机 → 启用 → 自定义服务器节点 |

日志：多人联机 → 分享联机核心日志（注意里面含网络地址）。

与[樱花内网穿透](https://github.com/zzy89216-gif/ZyNova/blob/main/docs/zh/frp.md)的区别：陶瓦双方都要装 ZyNova、走 P2P；
樱花只要房主有账号，对方用原版客户端也能连。
