# 渲染器总览

| 渲染器 | 状态 | 适用 |
|---|---|---|
| 自动 | 默认 | 不想选：按设备能力 + Minecraft 版本自动挑 |
| MobileGlues | 推荐 | 大多数设备（1.17 及以后） |
| Ironized Zink | 可选 | 想要桌面 OpenGL 4.x / 光影，且设备 Vulkan 驱动可用 |
| GL4ES | 兜底 | 老版本（1.16 及以前）/ 异常设备 |
| LTW | 实验性 | 仅 arm64，愿意承担风险 |

- **「自动」不是真正的渲染器**：它先看设备能不能跑（GLES 版本 / Vulkan），
  再按 **MobileGlues → GL4ES → Ironized Zink** 的顺序取第一个版本兼容的；
  只判断能不能跑，不测性能、不跑分。
- 在 **设置 → 渲染器** 里切换；选中具体渲染器后，**点它的状态卡片进详细设置页**调参数。
- 不要同时叠加多个渲染器插件。
- Ironized Zink 内置，无需渲染器插件；它的 OpenGL 版本与预设互相独立（见 `renderers.md`）。
