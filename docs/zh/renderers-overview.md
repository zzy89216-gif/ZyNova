# 渲染器总览

| 渲染器 | 状态 | 适用 |
|---|---|---|
| 自动 | 默认 | 不想选：按 Minecraft 版本自动挑 |
| MobileGlues | 推荐 | 大多数设备（1.17 及以后） |
| GL4ES | 兜底 | 老版本（1.16 及以前）/ 异常设备 |
| LTW | 实验性 | 仅 arm64，愿意承担风险 |

- **「自动」不是真正的渲染器**：它按 **Minecraft 版本**挑（不看 GPU 性能），
  顺序是 MobileGlues → GL4ES，第一个声明支持该版本的会被采用。
- 在 **设置 → 渲染器** 里切换；选中具体渲染器后，**点它的状态卡片进详细设置页**调参数。
- 不要同时叠加多个渲染器插件。
- Ironized Zink 已移除；需要 Zink 请用渲染器插件。
