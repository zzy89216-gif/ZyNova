# 故障排查

## 第一步：拿日志

- 游戏崩溃：崩溃页右上角「分享日志」；
- 启动器崩溃：设置 → 关于 / 日志入口；
- 运行日志：版本概览 →「运行日志」。

**截图不如日志**；崩溃页的「崩溃分析」只是启发式提示，最终以日志为准。

## 崩溃页会提示什么

崩溃页下方会显示「崩溃分析 · 怎么处理」，覆盖：

- 缺少前置模组；
- 模组加载失败 / Mixin 注入失败；
- 重复模组；
- Java 版本过低；
- 内存不足；
- 渲染器 / 图形驱动初始化失败；
- 文件损坏；
- 缺类 / 版本不匹配。

按提示处理后再启动；如果提示不准，把日志发出来。

## 常见问题

### 游戏一启动就闪退

1. 换渲染器（MobileGlues ↔ GL4ES）；
2. 换 Java（1.16 及以下 Java 8/11，1.17+ Java 17/21，1.20.5+ 通常 21）；
3. 删掉最近加的模组 / 光影；
4. 看日志里第一个 `Caused by`。

### 卡在加载界面

- 大型整合包首次启动会解压、下载库；看顶部任务进度；
- 内存太小会卡死；提高实例内存；
- 检查 `latest.log` 是否在反复重试某个下载。

### 下载失败 / 一直 0%

- 切换网络 / 关闭代理；
- 看任务面板的具体错误；
- CurseForge 资源可能需要镜像；Modrinth 通常可直连。

### 登录一直转圈

见 `login.md`；轮询问题已修，仍失败就换网络并重新登录。

### 收藏里没有我刚收藏的项目

- 在线收藏需要网络刷新；
- 确认点的是 ♥ 而不是下载按钮；
- 收藏页下拉刷新 / 重新进入。

### 安装 APK 失败

- 确认系统版本 ≥ Android 8（minSdk 26）；
- 卸载旧版再装（仅当签名不一致时）；
- 确认下载完整（对比文件大小）。

## 上报问题时请附上

1. 设备型号 / Android 版本 / GPU；
2. 启动器版本（设置 → 关于）；
3. 游戏版本 + 加载器；
4. 复现步骤；
5. 日志链接（不要只发截图）。
