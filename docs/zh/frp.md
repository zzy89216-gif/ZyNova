# 樱花内网穿透（联机）

ZyNova 提供两种联机方式，按场景选一种即可，**两者互不影响**：

| 方式 | 原理 | 需要 | 适合 |
|---|---|---|---|
| [陶瓦联机](https://github.com/zzy89216-gif/ZyNova/blob/main/docs/zh/terracotta.md) | P2P 组网（EasyTier），双方进入同一虚拟局域网 | 双方都装 ZyNova | 熟人开黑、不想开端口 |
| 樱花内网穿透 | 把本机端口映射到公网节点（frp） | 一个樱花账号 + 访问密钥 | 对方用电脑客户端、或不想装陶瓦 |

入口：**多人联机 → 樱花内网穿透**。

## 前提

1. 注册 [樱花内网穿透](https://www.natfrp.com/) 账号；
2. 在面板「用户信息 → 查看访问密钥」复制访问密钥；
3. 游戏里已经进入存档，并选择「对局域网开放」（端口不用记，见下文）。

> 免费账号的额度、实名要求与节点限制以樱花面板为准；本项目只做客户端，不代管账号。

## 第一次使用

1. 打开「樱花内网穿透」，粘贴访问密钥并登录；
   登录成功后页面顶部会显示你的**用户组（免费 / 白银 / 黄金…）、隧道额度、今日流量**；
2. 游戏里点「对局域网开放」，然后回到启动器点「新建隧道」：
   - 类型**固定 TCP**，不用选；
   - **本机端口自动识别**：启动器直接读系统里本应用正在监听的端口，
     也就是游戏刚刚开放的那个端口，不用手抄聊天栏；
   - 节点列表只会列出**你当前等级能用的节点**（免费号看不到白银/黄金专属节点）；
   - 远程端口留空，由樱花分配；
3. 保存后点这条隧道的「启动」；
4. 启动成功后，页面**最上方**会出现一行 `节点地址:远程端口`，点旁边的「复制」直接发给朋友，
   对方在游戏里「直接连接」即可。

## 关于端口（28.0.2 起靠游戏日志识别）

- Android 10 起 `/proc/net/tcp` 对普通应用不开放（真机日志里是 `EACCES: Permission denied`），
  所以现在**改读游戏日志**：原版「对局域网开放」时一定会写一行
  `[Server thread/INFO]: Local game hosted on port 5xxxx`，
  启动器从各游戏目录的 `logs/latest.log` 尾部取这一行；
- 所以**换世界、换端口都不用改隧道**：重新点一次「重新识别」即可；
- 只有在游戏还没「对局域网开放」、或日志被清掉时，才需要手动填聊天栏里的端口；
- 启动时如果端口没人监听，会明确提示「先在游戏里对局域网开放」，避免「隧道连上了但进不去」。

## 编辑隧道能改什么（28.0.2 起）

- 能改：**本机端口**、**备注**；
- **不能改名**：官方 `/tunnel/edit` 接口根本不接收 `name`（也没有 `remote`），
  以前提交上去会被静默忽略，看起来像「改了没反应」。需要改名只能**删掉重建**；
- 删除时如果服务端返回「已删除但没踢下线」，界面会提示你去樱花面板确认，不会再装作成功。

## ⚠️ 公开服务器只能用「多线」节点

樱花的硬规则（官方 OpenAPI 的创建接口里写得很清楚）：

- 如果这个服务器会发到**抖音 / B 站 / 小红书 / 论坛 / QQ 大群**等公开地方宣传、招人，
  就属于「公开游戏服务器」，**只能用「多线」节点**（节点 `flag & 2048`，名称里带「多线」）；
- 用了普通节点：**账号会被封，而且不退款**；
- 启动器这边：节点下拉列表会给这类节点标上 **「多线」**；
  创建隧道时服务端如果返回相关警告，会直接弹窗提醒你。

## 后台与息屏

- 启动隧道会开启**前台服务 + 常驻通知**，这是 Android 允许长期存活的方式；
- 首次使用建议点「允许后台运行」，把启动器加入电池优化白名单，否则息屏后隧道可能被系统杀掉；
- 部分国产 ROM（vivo / iQOO / 小米 / OPPO 等）还需要在系统设置里允许「后台高耗电 / 无限制」。

## 每次进页面都会刷新

樱花那边的隧道会变（额度、节点、封禁状态都可能变），所以**每次进入这个页面都会重新拉取**一次
账号与隧道列表；下拉或点刷新也可以手动拉。看到的永远是最新状态，不是缓存。

## 限制

- 免费用户有隧道数量、流量与带宽上限，以樱花面板为准；
- **公开游戏服务器只能使用专用的「多线」节点**，私人群内联机不受此限制；
- 同一条隧道**不能被两个客户端同时连接**（会互踢）；
- 樱花只是端口映射，不改变游戏本身的联机方式：房主仍需保持游戏运行。

## 安全

- 访问密钥用 **Android Keystore** 加密后保存在应用私有目录，其他应用读不到明文；
- 密钥只用于本次 `frpc` 进程的启动参数（官方形式 `frpc -f <密钥>:<隧道ID>`），
  不会写进日志、不会上传到任何服务器；
- 项目不内置任何账号或公共密钥，所有隧道都属于你自己的樱花账号。

## 排错

| 现象 | 处理 |
|---|---|
| 启动提示「端口没有程序监听」 | 先在游戏里「对局域网开放」，再点「重新识别」或手动填端口 |
| 启动提示「未找到 frpc 组件」 | 重新安装 APK（`libfrpc.so` 随包分发） |
| 隧道在线但朋友进不去 | 确认地址与端口、确认本机端口与游戏端口一致 |
| 刷新报「接口返回格式与预期不符」 | 28.0.1 起已兼容数组 / `{data}` / BOM；仍然失败请把日志里 `FrpApi` 那几行发出来 |
| 息屏后掉线 | 加入电池优化白名单，并在系统设置里允许后台运行 |

> 新建隧道时会校验名称 / 本机端口 / 节点；不合法会在对话框里直接标红提示（以前是点了没反应）。
