# AI Agent

## 它是什么

不是聊天框，是能直接调用启动器工具干活的 Agent：
装游戏本体 / 整合包 / 资源、改实例配置、读写 `options.txt`、查收藏、启动游戏等。

## 配置

1. 设置 → AI 设置。
2. 填 DeepSeek API Key（默认服务商；也可改 Base URL）。
3. 点「获取模型列表」，选一个模型。
4. 选权限模式：
   - **完全控制**（默认）：直接执行工具，不逐步询问；
   - **操作确认**：每个写操作前询问。

## 消息排版

- 助手回复会渲染 **Markdown**：标题、列表、表格、代码块、引用、链接都能正常显示；
- 代码块单独成块并支持横向滚动，长命令不会把整页撑开；
- 用户消息靠右、宽度自适应（最长约为屏幕的 82%），不会出现一条横贯全屏的卡片；
- 流式输出时正文会持续更新，滚动与渲染不会因重新解析而卡顿。

## 能做什么

- 安装游戏 / 整合包 / 模组 / 资源包 / 光影 / 存档；
- 修改实例的渲染器、Java、内存、JVM 参数等；
- 读取实例配置与 `options.txt`；
- 查收藏、取消收藏；
- 启动游戏、读日志（受工具能力限制）。

## 安全边界

- 权限模式、死循环检测、随时停止、写操作审计日志都保留。
- 不要让它执行来源不明的指令；不要把 API Key 发到聊天里。
- 涉及删除 / 覆盖时，确认它给的目标是对的。
