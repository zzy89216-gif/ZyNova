# 第三方认证

- 需要 Authlib-Injector 服务器地址（通常 `https://...`）。
- 地址必须可访问、证书有效。
- 登录失败先确认服务器本身是否正常。

## LittleSkin 快捷登录

「账号」→「添加账号」→ 登录菜单里的 **LittleSkin 快捷登录**：

- 点一下就直接弹账号密码框，不用自己查服务器地址（内置 `https://littleskin.cn/api/yggdrasil`）；
- 第一次用会顺手把 LittleSkin 加进认证服务器列表，以后也能从列表里进；
- 注册按钮会打开 LittleSkin 的注册页；
- 登录成功后可以在「更换皮肤」里改皮肤 / 披风，和第三方认证账号完全一样。

> 中文界面才显示离线 / 第三方 / LittleSkin 入口；其他语言只留微软登录。
> 切语言只是收起入口，**不会删除已有账号**，切回中文就回来了。
