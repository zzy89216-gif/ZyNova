# 自定义主页

卡片式主页最下方有一条资讯区，也就是「自定义主页」：用预设卡片看看 Minecraft 新闻、
版本更新和社区动态，**默认开启**，不用配置就有内容。

只有**卡片主页**显示这一区；主页类型在 设置 → 启动器 → 主页 → 主页类型 里切换
（空白 / 卡片主页 / 从本地加载 / 从网络加载）。资讯是装饰性内容，不影响启动与下载。

## 预设卡片

| 卡片 | 内容 |
|---|---|
| Minecraft 新闻 | Mojang 官方的新闻与版本公告 |
| Java 版本更新 | Java 版的版本更新记录 |
| Modrinth 动态 | Modrinth 上的热门 / 新内容 |
| CurseForge 资讯 | CurseForge 的精选内容 |
| Minecraft 社区活动 | 官方与社区活动 |

每张卡片最多展示 3 条；点条目会用浏览器打开来源页面。

## 开关与管理

- **总开关**：设置 → 启动器 →「自定义主页资讯」。关掉后主页完全不加载资讯（不联网、不读缓存）。
- **管理**：同一位置的「管理自定义主页卡片」打开管理弹窗：
  - 长按左侧手柄拖动，调整卡片顺序；
  - 每张卡右侧的开关是**隐藏**，隐藏后还能再打开；
  - 「删除」把卡片移到下方「可添加的卡片」，之后随时能加回来；
  - 「恢复默认」一键回到初始顺序、全部显示。

## 断网 / 加载失败

- 断网、超时或来源接口变更只影响对应的那一张卡片；
- 有缓存先显示缓存，没有就显示「暂时没有内容，稍后会自动刷新」；
- 主页的世界区、启动与下载不受影响，**完全断网也能正常启动游戏**。

## 隐私

这些资讯来自公开接口，不需要登录，也不会用到你的 Minecraft 或第三方账号信息。
