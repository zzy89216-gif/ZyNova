# 安装整合包

1. 「下载」→「整合包」。
2. 选 Modrinth / CurseForge 项目与版本。
3. 安装会创建新实例，并自动装前置与资源。
4. 首次启动可能还要下载库；看任务面板。

整合包不是普通资源，不能用「安装资源」入口硬塞。

## 导入本地整合包

1. 「下载」→「整合包」→ 右上角导入，选一个整合包压缩包（.mrpack / .zip / .curseforge 等）。
2. 启动器会先解包并询问实例名称，然后开始导入。
3. 导入过程在**后台任务**里跑：可以退出这个页面、切到别的应用，回来在任务面板里还能看到进度。
4. 想中途放弃，就在任务面板里取消——不会留下半个实例。

支持的格式：Modrinth（.mrpack）、CurseForge、MultiMC / Prism、HMCL 导出的整合包等；
不支持的格式会直接告诉你原因，不会装一半再失败。
