# 安装与首次启动

## 1. 选哪个 APK

每个版本只提供一个通用版 APK：

| 文件 | 适用设备 | 说明 |
|---|---|---|
| `ZyNova-<版本>.apk` | 所有 Android 设备 | 通用版，包含 arm64-v8a / armeabi-v7a / x86 / x86_64 |

以前的 `-arm64-v8a` 体积优化版已取消，通用版在 arm64 手机上同样是完整功能。
LTW 实验性渲染器只提供 arm64 库，在 32 位 / x86 设备上不会出现在渲染器列表里。

## 2. 安装

- 下载后直接安装；系统提示「未知来源」时，允许当前浏览器 / 文件管理器安装即可。
- 覆盖安装不会清空已有实例、账号与设置；**卸载不会删游戏数据**，只会清掉账号、设置与 Java 运行时
  （见 `data-and-privacy.md`）。
- 不需要 Root、Shizuku 或 ADB 才能启动游戏；这些只影响部分高级设备能力。

## 3. 首次启动

1. 选择语言与主题（设置 → 基础设置）。
2. 去「下载」页选一个 Minecraft 版本与加载器，安装游戏本体。
3. 去「设置 → 渲染器」确认渲染器：
   - 默认「自动」即可；遇到画面问题再手动换。
4. 去「账号」登录（微软 / 离线 / 第三方认证）。
5. 回首页选择实例 → 启动。

## 4. 存储与权限

- **游戏数据在公共目录** `/storage/emulated/0/ZyNova/.Minecraft/`（实例、存档、模组、资源包、光影、皮肤缓存），
  启动日志在同级的 `ZyNova/logs/`，文件管理器里直接能看到。
- **必须授予「所有文件访问」**（Android 11+）：没有它读写不了 `/ZyNova`，启动页会拦住并引导你去开启。
  这是硬门槛，不是可选项——游戏数据要放在用户能直接拿到的地方，就只能要这个权限。
- Java 运行时与 JNA 留在应用私有目录（公共存储是 noexec，放那里游戏起不来），卸载应用会清掉。
- 首次启动会依次经过：地区检查 → 存储权限 → 3 份声明与年龄 →（老用户）数据迁移 → 主界面。

> 小提示：还没有安装任何版本时，首页左侧会直接给一个「下载一个实例」按钮，点了就进这里（下载 → 游戏）。
