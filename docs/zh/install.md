# 安装与首次启动

## 1. 选哪个 APK

27.9.0 起每个版本提供两个 APK：

| 文件 | 适用设备 | 说明 |
|---|---|---|
| `ZyNova-<版本>.apk` | 所有 Android 设备 | 通用版，包含 arm64-v8a / armeabi-v7a / x86 / x86_64 |
| `ZyNova-<版本>-arm64-v8a.apk` | 仅 arm64 设备 | 体积更小；不包含 32 位与 x86 库 |

绝大多数手机选**通用版**最稳；确认自己是 arm64 且想省空间再选 arm64 版。
LTW 实验性渲染器只提供 arm64 库，在 32 位 / x86 设备上不会出现在渲染器列表里。

## 2. 安装

- 下载后直接安装；系统提示「未知来源」时，允许当前浏览器 / 文件管理器安装即可。
- 覆盖安装不会清空已有实例、账号与设置；**卸载会清空应用私有目录**（见 `data-and-privacy.md`）。
- 不需要 Root、Shizuku 或 ADB 才能启动游戏；这些只影响部分高级设备能力。

## 3. 首次启动

1. 选择语言与主题（设置 → 基础设置）。
2. 去「下载」页选一个 Minecraft 版本与加载器，安装游戏本体。
3. 去「设置 → 渲染器」确认渲染器：
   - 默认「自动」即可；遇到画面问题再手动换。
4. 去「账号」登录（微软 / 离线 / 第三方认证）。
5. 回首页选择实例 → 启动。

## 4. 存储与权限

- 游戏、实例、Java 运行时都在应用私有目录；卸载应用会一起删除。
- 导出整合包 / 日志 / 截图时才会通过系统文件选择器访问外部存储，不需要「所有文件访问」权限。
- 如果使用了自定义背景、整合包导入等需要文件选择的功能，按系统弹窗授权对应目录即可。
