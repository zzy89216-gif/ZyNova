# 任务面板

- 顶部细进度条只在有任务时出现。
- 点它展开：标题 / 步骤 / 进度 / 百分比 / 速度 / 取消。
- 任务结束自动收起；面板本身不会自己弹出来挡界面（安装完成、需要输入名字这类提示会另外弹，
  在任何页面都会出现，见 [downloads.md](downloads.md)）。

## 哪些任务在面板里跑

下面这些**都在后台继续**，可以离开页面、切到别的应用，回来照样能看到进度：

- 游戏本体安装；
- 整合包下载安装；
- **整合包导入**（选本地压缩包导入）。

如果进程被系统杀掉，下次启动会自动做安全恢复（清理半成品 / 回滚覆盖安装 / 整合包残留清理并提示重装）。

想放弃就在面板里点取消——对应的安装器 / 导入器会一起停掉，不会「界面说取消了、后台还在写文件」；
取消后任务状态会复位，不会卡在「安装中」。
