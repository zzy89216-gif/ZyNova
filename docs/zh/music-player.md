# 内置音乐播放器

启动器自带一个轻量音乐播放器：导入本地音乐、列表播放、看歌词，进游戏也能切歌，不用再装第二个 App。

## 入口

- 启动器顶栏胶囊里的「音乐」；
- 顶栏下方的「正在播放」迷你条：不在音乐页时，只要还有当前曲目就显示（暂停时也在），
  左边是歌名，右边是播放 / 暂停、上一首 / 下一首；点条身直接进音乐页；
- 游戏内：打开启动器菜单（屏幕上那个悬浮菜单）→ 右栏「音乐」，弹层里直接控制，不用退出游戏。

## 导入音乐

- 点「导入」→ 系统文件选择器，可以一次多选；
- 支持 MP3、AAC（M4A）、FLAC、OGG / Opus、WAV 等常见音频格式，不是音频的文件会跳过并提示；
- 选中的文件会**复制进启动器私有目录**（`files/music/`），之后删掉原文件也不影响播放；
- 同名的文件会自动改名，不会互相覆盖；
- 歌词**不用**和音频一起选，导入后单独给某首歌加就行（见「歌词」）。

## 选歌与播放

- 点曲库列表里的任意一首就切到这首，正在播放的那一行会高亮；
- 播放 / 暂停、上一首 / 下一首；
- 进度条：拖动时显示你拖到的位置，松手就跳到那里；当前进度和总时长一直显示，暂停后也不会停住或消失；
  总时长还读不出来时显示 `--:--`；
- 一首放完自动播下一首（列表循环）；
- 会记住上次播放的曲目和进度，下次打开接着放；
- 每条曲目右侧的删除图标可以删掉这首（只删启动器里的副本，不动你的原文件）。

## 歌词

- 给一首歌加歌词：在音乐页点「导入歌词」，选任意一个 `.lrc` 文件（只接受 `.lrc`，选错格式会提示）——
  **不需要和歌同名**，导入后当前这首**立刻**显示歌词，不用重开播放器；
- 导入时会把歌词复制成应用私有目录里的 `files/music/<音频完整文件名>.lrc`（例如 `晴天.mp3.lrc`）——
  同名的 `.mp3` 和 `.m4a` 各自有一份歌词，不会互相覆盖；以前导入的歌词也仍然能显示；
- 切歌或导入歌词后解析需要一小会儿，歌词区会先显示「歌词加载中…」，解析完自动切成歌词（或「没有歌词」提示）；
- 播放时当前这句高亮，上下还能看到相邻几句，并会自动滚到当前行；
- 支持常见 LRC 时间标签（`[mm:ss]`、`[mm:ss.xx]`）：一句带多个时间标签会按每个时间点分别显示；
  没有时间标签的行（比如「作词：」这类说明）会被跳过，不影响其它行；
- 歌词文件编码不用自己转，UTF-8 / UTF-16（带 BOM）/ GBK 会自动识别；
- 歌词文件最大 1 MiB；超过上限、或者文件里读不出任何带时间标签的行时，会提示没能读到歌词；
- 没有歌词的歌不会报错，歌词区只会提示还没有歌词。

## 后台播放

- 播放时通知栏会出现控制：播放 / 暂停、上一首 / 下一首；把通知划掉就是停止播放；
- 这首歌有歌词时，通知栏会显示**上一行 + 当前这句**，展开通知能看全两行（只在歌词换行时更新，不会一秒刷一次）；
- 暂停时通知栏显示「已暂停」，不会继续显示歌词；
- 切到别的应用、回到桌面都继续放；
- Android 13 及以上需要允许通知才有通知栏控制；通知权限被拒时前台照常能放，只是没有通知栏按钮。

## 声音与耳机

- 别的 App 抢音频焦点时，播放器会让位暂停，不会和游戏或别的 App 抢声音；
- 拔掉耳机自动暂停。

## 限制

- 不支持 APE、WMA、DSD 等格式；
- 歌词只支持常见 LRC 时间标签，**不支持逐字歌词**（krc 等格式）；
- 没有封面、没有在线音乐；
- 不支持锁屏 / 蓝牙耳机上的媒体键控制。

## 换设备 / 卸载

- 曲库在应用私有目录 `files/music/`，普通文件管理器看不到；歌词文件也在这里，和音频完整文件名同名（如 `晴天.mp3.lrc`）；
- **卸载启动器会一并删除曲库（含歌词）**，想留着就把文件另存一份。
