# 自动渲染器

- 行为：每次启动时，按「这台设备跑不跑得动 → 渲染器偏好顺序 → Minecraft 版本兼容」挑一个。
- 偏好顺序：**MobileGlues → GL4ES → Ironized Zink**。
  - MobileGlues：需要设备支持 OpenGL ES 3.2 及以上，不满足会自动跳过；
  - GL4ES：只要版本在它的覆盖范围内就优先用它（老设备最稳）；
  - Ironized Zink：需要设备有可用的 Vulkan 驱动，主要补 1.21.4 之后的新版本。
- 只判断「能不能跑」，**不**测性能、不跑分；不会写回你的设置，换实例仍按各自配置。
- 一个都挑不出来时（比如版本超出所有候选范围），会退回「版本兼容的第一个渲染器」并记日志，不会把启动卡死。
- LTW 是实验性，不参与自动选择。
- 想知道这次实际用了谁：进游戏前先在 设置 → 渲染器 里看「自动」下面的说明，或翻日志里的 `Auto renderer picked ...`。
