# 从收藏安装

## 一键下载到当前实例

从「版本设置 → 资源管理 → 下载资源」进入资源页时，收藏页会带上该实例的上下文：

- 卡片右侧出现下载按钮，点一下就把资源下载并装进这个实例；
- 必需前置（例如模组的前置模组）会一起下载安装，不需要自己再去找；
- 前置确实找不到时会明确提示缺了哪些，不会装作装好了。

从主页「资源中心」进入时没有实例上下文，下载按钮会把资源装进**当前实例**；想换目标实例，从该实例的「版本设置 → 资源管理」进来即可。
点卡片本身仍然是进详情（看类型、大小、校验结果）。

## 本地归档

- 有实例上下文时，「安装」直接复制进该实例（同样自动补齐能识别的前置），不再弹实例选择；
- 没有上下文时仍然弹出实例列表让你选；
- 无法在线识别的文件会直接复制，前置需要手动补。
