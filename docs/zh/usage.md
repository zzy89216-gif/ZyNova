# 日常使用

## 界面

- 顶部是**居中的液态玻璃胶囊**，从左到右依次是：
  **主菜单 / AI / 多人 / 下载 / 音乐 / 文件 / 设置**；
- 标题在左上角；进入子页面后，左上角会出现返回键；
- 有下载任务时，胶囊右端会出现一个小圆环，点它展开任务面板；
- 不在音乐页时，顶栏下方还会有一条紧凑的「正在播放」迷你条：左边是歌名，右边是播放 / 暂停、上一首 / 下一首，
  点条身进音乐页。暂停时也显示；只导入还没点播、或没有当前曲目时自动收起；
- 外观相关选项（主题、壁纸、圆角、玻璃、背景模糊等）在 **设置 → 启动器** 里；顶栏没有单独的「个性化」入口。

## 下载与安装游戏

1. 顶部胶囊 →「下载」。
2. 选择「游戏」→ 选 Minecraft 版本 → 选加载器（Vanilla / Fabric / Quilt / Forge / NeoForge 等）。
3. 点安装，进度在顶部细进度条；点它可展开任务面板（标题 / 步骤 / 进度 / 速度 / 取消）。
4. 安装完成后回首页，实例会自动出现。

> 下载 / 安装可以**同时开多个**：不用等上一个结束就能再发起，任务面板里一个任务一行，
> 各自进度、速度和取消互不影响。整合包、模组、资源包、光影、存档都在同一个「下载」入口，按左侧分类切换。

## 实例管理

- 进入实例页：在「版本」列表里点实例条目。
- 「版本设置」可改 Java、内存、渲染器、分辨率、JVM 参数等。
- 「模组管理」可启用 / 禁用 / 删除模组；Fabric API 由 Fabric 流程自动加入，不允许手动重复安装。
- 「运行日志」在版本概览页，崩溃时优先从这里分享日志。

### 删除已安装的版本

- 入口：**版本列表** → 版本条目右侧菜单 →「删除」→ 确认「删除版本」。
- 删除时是**全屏进度**，先统计文件（文件数 + 大小），再按文件逐个删，显示百分比、文件数、已删 / 总大小和当前文件；
  不会再看不出进度、像卡死。删除期间可以随时取消。
- 取消时会把版本**尽量恢复**回列表：还没删到的文件都在；如果取消前已经删掉部分文件，结束提示里会写明删了多少个。
- 删除范围是 `./versions/<版本名>` 目录下的所有文件；开了版本隔离时，这个版本的存档、资源包、模组等也在这个目录里。
  **删前先把要留的存档 / 配置备份出去。**

## 主页

主页默认是**卡片式**（设置 → 启动器 → 主页 → 主页类型 里可切换空白 / 卡片主页 / 从本地加载 / 从网络加载），从上到下是：

1. **最近游玩的**：跨实例汇总最近玩过的世界，最多显示 4 个；点世界直接进游戏，第 5 张「查看全部」进入**全部世界**列表（搜索、排序、按实例 / 游戏版本筛选，可直接启动），详见 [安装 / 导入存档](https://github.com/zzy89216-gif/ZyNova/blob/main/docs/zh/install-world.md)；
2. **自定义主页**：世界区下方的资讯卡片（Minecraft 新闻 / Java 版本更新 / Modrinth / CurseForge / Minecraft 社区活动），
   **默认开启**；开关在 设置 → 启动器（「自定义主页资讯」），卡片可以添加、删除、隐藏、拖动排序。
   断网或请求失败时用本地缓存，不影响主页其它功能，详见 [自定义主页](https://github.com/zzy89216-gif/ZyNova/blob/main/docs/zh/custom-home.md)。

## 导出

- 实例页 → 导出 → 目前**只支持 Modrinth 整合包格式**。
- 可选择是否把 Modrinth / CurseForge 的远程资源写入索引；导出前会提示。
- 导出的 `.mrpack` 可被常见第三方启动器导入。

## 收藏

- 在资源搜索结果卡片或项目详情页点 ♥ 即可收藏。
- 收藏页分「在线收藏」与「本地归档」：前者是链接，后者是复制进私有目录的文件。
- 收藏卡片右侧是一个大号下载按钮：点一下直接装进实例（含必需前置）；小的 ♥ 才是取消收藏。
- 详见 `favorites.md`。

## 常见入口

| 想做什么 | 去哪 |
|---|---|
| 换渲染器 | 设置 → 渲染器 |
| 改内存 / Java | 实例 → 版本设置 |
| 看崩溃原因 | 崩溃页 →「崩溃分析 · 怎么处理」 |
| 分享日志 | 崩溃页右上角 / 版本概览 → 运行日志 |
| 配 AI | 设置 → AI 设置 |
| 找某个存档 | 主页「最近游玩的」→「查看全部」 |
| 关掉主页资讯 | 设置 → 启动器 |

## 游戏内的返回键和 ESC

- **返回键只开关启动器菜单**：在游戏里按返回，弹出的是启动器的控制菜单（鼠标 / 手柄 / 手势 / 陀螺仪、日志、退出等），不会再到游戏里乱跳；
- **要进 Minecraft 自己的暂停菜单**：打开启动器菜单 → 点「发送 ESC（游戏暂停菜单）」；
- 菜单里还有「回到启动器主界面」：**不停止游戏**，回来还是原来那一局；
- 菜单里的「多人联机」：收起菜单、回到启动器并**直接打开「多人联机」页**（陶瓦 / 樱花都在这一页），
  **游戏不退出、继续在后台跑**；
- 想临时改控制设置、看日志、切输入法，都在这个菜单里，不用退出游戏。
