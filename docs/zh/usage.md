# 日常使用

## 界面

- 顶部是**居中的液态玻璃胶囊**，从左到右依次是：
  **主菜单 / AI / 多人 / 下载 / 文件 / 个性化 / 设置**；
- 标题在左上角；进入子页面后，左上角会出现返回键；
- 有下载任务时，胶囊右端会出现一个小圆环，点它展开任务面板；
- 外观相关选项的完整集合在 **设置 → 通用**；顶部「个性化」只是它的快捷入口。

## 下载与安装游戏

1. 顶部胶囊 →「下载」。
2. 选择「游戏」→ 选 Minecraft 版本 → 选加载器（Vanilla / Fabric / Quilt / Forge / NeoForge 等）。
3. 点安装，进度在顶部细进度条；点它可展开任务面板（标题 / 步骤 / 进度 / 速度 / 取消）。
4. 安装完成后回首页，实例会自动出现。

> 整合包、模组、资源包、光影、存档都在同一个「下载」入口，按左侧分类切换。

## 实例管理

- 首页长按 / 点击实例卡片进入实例页。
- 「版本设置」可改 Java、内存、渲染器、分辨率、JVM 参数等。
- 「模组管理」可启用 / 禁用 / 删除模组；Fabric API 由 Fabric 流程自动加入，不允许手动重复安装。
- 「运行日志」在版本概览页，崩溃时优先从这里分享日志。

## 导出

- 实例页 → 导出 → 目前**只支持 Modrinth 整合包格式**。
- 可选择是否把 Modrinth / CurseForge 的远程资源写入索引；导出前会提示。
- 导出的 `.mrpack` 可被常见第三方启动器导入。

## 收藏

- 在资源搜索结果卡片或项目详情页点 ♥ 即可收藏。
- 收藏页分「在线收藏」与「本地归档」：前者是链接，后者是复制进私有目录的文件。
- 详见 `favorites.md`。

## 常见入口

| 想做什么 | 去哪 |
|---|---|
| 换渲染器 | 设置 → 渲染器 |
| 改内存 / Java | 实例 → 版本设置 |
| 看崩溃原因 | 崩溃页 →「崩溃分析 · 怎么处理」 |
| 分享日志 | 崩溃页右上角 / 版本概览 → 运行日志 |
| 配 AI | 设置 → AI 设置 |
