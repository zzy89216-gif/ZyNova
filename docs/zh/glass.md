# 玻璃材质

> 「动态玻璃」开关已删除：玻璃是全应用统一的基础材质，不再是可开关的特效。
> 想看具体怎么调，见 [个性化与玻璃氛围](https://github.com/zzy89216-gif/ZyNova/blob/main/docs/zh/personalization.md)。

- 全应用只有**一层**背景模糊：在背景层里模糊一次，卡片 / 按钮 / 对话框不再各自模糊。
- 卡片材质 = 竖直低透明度渐变 + 1px 亮边；深色主题用白色系、浅色主题用黑色系。
- 没有任何常驻动画：滚动、拖动、翻页都不会重建背景，也不会触发阴影或模糊重算。
- 「玻璃强度」在 个性化 页（或 设置 → 通用）里调，范围 2%–16%，默认 8%。
- 卡顿 / 发热时：把「背景模糊」调到 0–8dp，或把「背景不透明度」调到 100%（此时模糊会自动跳过）。
