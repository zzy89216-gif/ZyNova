# 首次启动

## 0. 地区检查与存储权限

1. **地区检查**：暂未开放的地区会显示阻断页，只能退出。
2. **存储权限**：必须允许「所有文件访问」（Android 11+），否则读写不了公共目录 `/ZyNova`，
   这一步不给权限就进不去主界面——权限页里有按钮直接跳到系统开关。

## 1. 三份声明（新装必读）

第一次启动会依次展示三份文档，**每份都要滑到底部并单独勾选**才能进入下一份：

1. 《最终用户许可协议 + 隐私政策》
2. 《第三方开源合规声明 + 补充免责与风险告知》
3. 《使用教程 + 适用地区与法律管辖》

- **文字跟随系统语言**，**条款跟随所在地区**：同一份声明，中国用户与美国用户看到的补充条款不同（数据保护法、监管机构、未成年年龄、争议管辖）。
- **老版本升级不会重新弹**：只有条款内容实质更新时才会要求重新阅读；换系统语言、改时区都不再触发。
- 如果所在地区暂未开放，会显示阻断页，只能退出；阻断页会写明判定依据（国家 / 时区 / 语言）。

## 2. 老用户升级：数据迁移

如果游戏数据还在应用私有目录，会先显示一个**全屏迁移页**，把实例和启动器数据搬到 `/ZyNova/.Minecraft`：

- 进度条会显示百分比与正在复制的文件；
- **搬完不会自动进主界面**，要手动点「下一步」；
- 中途退出没关系，下次打开会接着搬；失败会清掉半成品并回退旧目录。

## 3. 进入主界面之后

1. 选语言 / 主题（设置 → 基础设置）。
2. 去「下载」装一个游戏本体。
3. 设置 → 渲染器，先保持「自动」。渲染器列表只显示当前设备能跑的那些。
4. 账号页登录（微软 / 离线 / 第三方）。
5. 首页选实例 → 启动。

第一次启动会解压运行库，时间取决于设备；不要中途杀进程。
