# 在线收藏

- 资源卡片 / 详情页点 ♥ 收藏。
- 收藏页 →「在线收藏」查看；可刷新远端信息。
- 卡片是**简化版**：只有图标、标题、作者与类型，不显示简介和下载量；点卡片进详情。
- 右侧两个按钮：**大的那个是下载**（点一下直接装进实例，含必需前置），**小的那个是取消收藏 ♥**。
- 只存项目 ID 与缓存；断网不能安装。
- 下载会按「进入资源页时所在的实例」判断兼容性：没有该实例版本的资源会说明目标实例（Minecraft 版本 + 加载器），
  并给「查看全部版本」入口；卡片上也会标出「无 1.20.1 版本」这类提示。
- 取消收藏会先确认一次，已经归档的本地文件不受影响。
