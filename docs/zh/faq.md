# 常见问题速查

**Q：需要 Root / Shizuku 吗？**
A：启动游戏不需要；只有部分设备能力（高级文件操作等）才需要。

**Q：支持正版登录吗？**
A：支持微软设备代码流；也保留离线与第三方认证。

**Q：哪个渲染器最好？**
A：默认「自动」。大多数设备 MobileGlues；老版本或异常时 GL4ES；LTW 是实验性，不推荐。

**Q：Ironized Zink 去哪了？**
A：27.9.0 已移除；需要 Zink 请用渲染器插件。

**Q：为什么有两个 APK？**
A：通用版兼容所有 ABI；arm64 版体积更小，只给 arm64 设备。

**Q：卸载会删游戏吗？**
A：会。实例、Java、收藏归档都在应用私有目录；卸载即清空。重要存档先导出。

**Q：AI 会自己删东西吗？**
A：完全控制模式下会直接执行写操作；可在「操作确认」模式逐步确认。审计日志保留。

**Q：日志里会有隐私吗？**
A：可能包含账号 ID、服务器地址、文件路径；分享前自己看一眼，不要发 Token。

**Q：界面卡 / 掉帧？**
A：27.10.2 起玻璃只有一层背景模糊、没有任何常驻动画。仍卡的话到
[个性化页](https://github.com/zzy89216-gif/ZyNova/blob/main/docs/zh/personalization.md)把「背景模糊」调小，
或把「背景不透明度」拉到 100%（此时模糊会自动跳过）。

**Q：怎么反馈？**
A：GitHub Issues 选对应模板；不确定选「其他 / 不确定」，或先来 Discord。
