# 崩溃日志在哪

崩溃了先找日志，截图不如日志——里面通常有第一个 `Caused by`。

| 崩溃类型 | 去哪看 |
|---|---|
| 游戏崩溃 | 崩溃页右上角「分享日志」；日志在 `<实例>/crash-reports/` 与 `<实例>/logs/latest.log` |
| 启动器崩溃 | 崩溃页会列出堆栈；文件在 `/ZyNova/logs/launcher_crash.log` |
| 启动器运行日志 | `/ZyNova/logs/`（公共目录，文件管理器直接能看到） |
| 游戏运行日志 | 实例页 →「运行日志」 |
| 联机（陶瓦） | 联机菜单 →「查看日志」；要发给别人就回联机页点「分享联机核心日志」 |
| 樱花穿透 | 页面底部日志卡片会保留 `frpc` 输出 |

> `ZyNova` 就是公共存储里那个文件夹：`/storage/emulated/0/ZyNova/`。
> 日志里的 Token、`Bearer`、`password=` 这类内容会被自动打码，分享前还是建议扫一眼。
