# 登录与账号

## 三种入口

1. **微软正版**：设备代码流；不需要 Client Secret，也不需要 Redirect URI。
2. **离线账号**：只填用户名；用于离线游戏与部分服务器。
3. **第三方认证**：Authlib-Injector 服务器地址 + 账号。

## 微软登录流程

1. 账号页 → 添加账号 → 微软。
2. 启动器显示设备代码与验证链接。
3. 在浏览器打开链接、输入代码、完成授权。
4. 回到启动器，等待轮询拿到令牌。

> 轮询不会被 400 响应误判为致命错误；
> `authorization_pending` / `slow_down` 会继续等，4xx 才会立即失败。

## 常见错误

| 现象 | 处理 |
|---|---|
| 一直转圈 / 不结束 | 确认浏览器里已完成授权；网络可直连 Microsoft；换网络重试 |
| `invalid_grant` | 刷新令牌失效或被撤销；删除账号重新登录 |
| `XErr 2148916233` | 该微软账号没有 Xbox 档案；先去 Xbox 官网创建 |
| 提示地区 / 年龄限制 | 按微软提示处理；启动器无法绕过 |
| 第三方认证失败 | 检查服务器地址是否以 `https://` 开头、是否可访问 |

## 安全

- 启动器只保存令牌，不保存微软密码。
- 不要把账号令牌、日志里的 Authorization 头发给别人。
