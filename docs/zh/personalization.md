# 个性化与玻璃氛围

27.10.2 起，启动器的观感调整从「设置 → 通用」里独立出来，集中到一个页面：
**顶部胶囊的调色盘按钮 → 个性化**。

这一页只放最高频的 5 项，其余低频选项仍然在 设置 → 通用，
**两处读写的是同一套配置**，不会出现「这边改了、那边又改回去」的分叉。

## 页面上有什么

| 项目 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 壁纸 | 图片 / 视频 | 无 | 真正的选图流程仍在 设置 → 通用（需要系统选择器） |
| 背景不透明度 | 20%–100% | 80% | 拉满 100% 时背景完全不透明，会**自动跳过模糊**以省性能 |
| 背景模糊 | 0–40dp | 0 | 实际半径上限 24dp；核心数 ≤ 4 的设备自动降到 12dp |
| 卡片圆角 | 12–36dp | 28dp | 统一驱动全应用圆角（面板 ×1.36、输入框 ×0.54…） |
| 玻璃强度 | 2%–16% | 8% | 卡片上那层单色渐变的浓度，调低更接近纯色 |

页面底部还有「更多设置 →」，直接跳 设置 → 通用。

## 玻璃是怎么画的

从 27.10.2 起，「动态玻璃」这个概念被彻底删掉了：

- **只有一层模糊**：背景层在 `Background()` 里模糊一次，卡片、按钮、对话框都不再各自模糊；
- **没有常驻动画**：原来那条沿对角线流动的高光、以及首页按钮的流光，全部移除；
- **卡片材质** = 竖直低透明度渐变 + 1px 亮边：深色主题用白色系、浅色主题用黑色系，
  所以任何壁纸下都是单色的，不会有彩色玻璃那种「很怪」的观感。

这样做的直接结果是：滚动、拖动、翻页时**不会触发背景重建**，
低端机也不会因为弹窗叠第二层糊而掉帧。

## 什么时候该调哪个

- 觉得**界面太素**：把「玻璃强度」调到 12%–16%；
- 觉得**卡片糊成一片**：把「玻璃强度」调到 2%–4%，或把「卡片圆角」调小；
- 老手机**掉帧**：背景模糊调到 0–8dp，不透明度调到 100%（此时模糊会自动跳过）；
- 想要**纯色极简**：玻璃强度 2% + 圆角 12dp。

## 相关

- 按钮层级：主操作按钮的底色比卡片深 2~3%（深色主题 ×1.05 / 浅色主题 ×0.96）并带 1px 描边，
  「启动游戏」与「创建世界」相邻时不会糊成一块；
- 设置 → 通用里仍然保留壁纸选择、背景视频音量、主题色、深色模式、语言、全屏等选项。
