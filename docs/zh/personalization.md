# 个性化与玻璃氛围

入口：**顶部胶囊的调色盘按钮**。原来散在「设置 → 通用」里的高频选项，现在单独成页。

| 项目 | 范围 | 默认 |
|---|---|---|
| 壁纸 | 图片 / 视频 | 无 |
| 背景不透明度 | 20%–100% | 80% |
| 背景模糊 | 0–40dp（实际上限 24dp） | 0 |
| 卡片圆角 | 12–36dp | 28dp |
| 玻璃强度 | 2%–16% | 8% |

底部「更多设置」进 设置 → 通用；两处改的是同一份配置。

## 玻璃是怎么画的

- **只有一层模糊**：背景层模糊一次，卡片 / 按钮 / 对话框不再各自模糊；
- **没有常驻动画**：低端机滚动、翻页也不掉帧；
- **卡片材质** = 竖直低透明度渐变 + 1px 亮边（深色用白、浅色用黑），任何壁纸下都是单色。

## 怎么调

- 太素 → 玻璃强度 12%–16%；
- 卡片糊在一起 → 玻璃强度 2%–4%，或把圆角调小；
- 老手机掉帧 → 模糊 0–8dp，不透明度拉满（模糊会自动跳过）。
