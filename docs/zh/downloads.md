# 下载与任务

- 每个安装任务都会出现在顶部那条细进度条上；点它展开：标题 / 步骤 / 进度 / 速度 / 取消。
- 游戏、整合包、资源共用一个队列，可以同时跑多个。
- 取消会真的停掉安装器，不只是关掉界面。
- 这些任务**都在后台继续**：离开下载页、切到别的应用、甚至临时旋转屏幕都不会中断；
  回来在任务面板里照样能看到进度。
- 整合包的**本地导入**也走这个队列（不再是弹窗挡住界面），详细步骤见 [install-modpack.md](install-modpack.md)。
- **一键下载 / 一键安装**：从「版本设置 → 资源管理」进入资源下载页时，模组 / 资源包 / 光影 / 存档的卡片右侧会出现下载按钮，
  点一下就把这一版连同**必需前置**装进当前实例，不必先进详情页；整合包的版本列表也是每行一个按钮，点一下直接装这一版。
