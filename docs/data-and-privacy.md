# 数据与隐私

## 数据放在哪

| 内容 | 位置 |
|---|---|
| 实例 / 游戏文件 | 应用私有目录 |
| Java 运行时 | 应用私有目录 |
| 收藏归档 | 应用私有目录 `files/favorites/` |
| 设置 / 账号令牌 | MMKV（应用私有） |
| MobileGlues 配置 | 应用私有目录 `mobileglues/config.json` |

## 卸载

卸载应用会删除整个私有目录，包括实例、存档、收藏归档、账号与设置。
需要保留的内容请先导出（存档 / 整合包 / 日志）。

## 日志上传

- 只有你主动点「分享链接」才会上传到公共日志平台；
- 上传前先确认日志里没有 Token、Cookie、服务器密码；
- 崩溃分析在本地完成，不上传日志。

## API Key

- AI 的 API Key 存在应用私有设置里；
- CurseForge API Key 由构建时注入 APK（上游设计），不在仓库文档中公开；
- 不要把任何 Key 写进 Issue / 截图 / 聊天记录。
