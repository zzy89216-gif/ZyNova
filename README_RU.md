## ✦ О проекте

**ZyNova** — **неофициальный** лаунчер Minecraft: Java Edition для Android, созданный на основе
открытого кода [ZalithLauncher2](https://github.com/ZalithLauncher/ZalithLauncher2).

> **ZyNova не является официальной версией ZalithLauncher2.**
>
> Это независимый неофициальный форк, который поддерживается и распространяется отдельно.

## ✨ Что нового в 27.7.2

- **Избранное объединено**: онлайн-избранное (Modrinth / CurseForge, установка в один клик с автозагрузкой зависимостей) и локальный архив — две секции на одной странице; также доступно из боковой панели загрузок
- **Страницы рендереров разделены**: MobileGlues / Ironized Zink / GL4ES теперь на отдельных страницах
- **Настройки разделены на семь категорий**: Основные / Игра / Рендерер / Сеть и загрузки / AI / Дополнительные / О программе
- **Сеть и загрузки**: можно менять число соединений, таймауты подключения и чтения, число повторов; источник загрузки задаётся отдельно для каждого сервиса (неверный адрес автоматически откатывается к официальному); доступны просмотр и очистка кеша
- **Настройки рендереров объединены**: показываются только параметры выбранного рендерера, все доступные параметры собраны в «Дополнительных настройках»
- **Настройки AI перенесены в общие настройки**: отдельный вход из чата убран, подсказка при первой настройке сохранена, существующие API-ключ, модель и режим прав не меняются
- **Избранное и локальный архив**: ресурсы копируются в приватное хранилище приложения с дедупликацией по SHA-256; установка в экземпляр с автозагрузкой обязательных зависимостей, проверка целостности, экспорт и независимое удаление
- **Оптимизирован запуск с видеофоном**: плеер больше не создаётся при инициализации интерфейса, видео проявляется после первого кадра — без белой вспышки
- **Загрузки и установка идут в фоне**: уход со страницы загрузки не прерывает установку
- **Создание мира**: в хардкоре читы и сохранение инвентаря принудительно отключены
- **Загрузка NeoForge**: прогресс считается по реальным байтам, при остановке выводится причина, повторы не начинаются с нуля

> Полный список изменений прошлых версий — в [CHANGELOG.md](CHANGELOG.md).

## 🛠️ Возможности

### AI Agent

Встроенный AI Agent умеет читать логи, управлять модами, менять настройки, устанавливать ресурсы
и запускать игру. По умолчанию используется DeepSeek; поддерживается также OpenAI-совместимый API.
Список моделей запрашивается у провайдера, API Key и Base URL хранятся отдельно.

### Рендереры

- **Настройки из семи категорий**: Основные / Игра / Рендерер / Сеть и загрузки / AI / Дополнительные /
  О программе — здесь же настраиваются параметры рендереров и источник загрузки для каждого сервиса
- **Избранное и локальный архив**: ресурсы копируются в приватное хранилище с дедупликацией по SHA-256;
  установка в экземпляр с автозагрузкой зависимостей, проверка целостности, экспорт и отдельное удаление
- **Авто**: выбор совместимого рендерера по версии Minecraft
- **MobileGlues**
- **Ironized Zink**
- **GL4ES**

### Карточный главный экран

Установленные инстансы показаны карточками. С карточки можно запустить мир или сервер, а также
создать новый мир / добавить сервер. Размер карточек, порядок и материал кнопок настраиваются.

### Единое управление ресурсами

Поиск в Modrinth / CurseForge, проверка совместимости версий, рекурсивная установка зависимостей,
загрузка, проверка SHA1 и установка объединены в один процесс. Уже установленные файлы и
дублирующиеся проекты пропускаются автоматически.

### Проверка Vulkan

Лаунчер проверяет поддержку Vulkan на устройстве и драйвере, чтобы помочь с выбором рендерера.

## 📦 Сборка (для разработчиков)

### Требования

- JDK 17
- Android SDK / NDK
- Gradle (используйте wrapper из репозитория)

### Сборка

```bash
./gradlew ZalithLauncher:assembleRelease
```

Релизная сборка использует обфускацию и сокращение ресурсов, вместе с ней создаётся `mapping.txt`.
Официальные сборки выполняются в GitHub Actions и представляют собой один универсальный APK.
