Лаунчер Minecraft: Java Edition для Android на основе исходников ZalithLauncher2. Поддерживается независимо.

- GitHub：<https://github.com/zzy89216-gif/ZyNova>
- Issues：<https://github.com/zzy89216-gif/ZyNova/issues>
- Discord：<https://discord.gg/QwPpZQHrTa>

## ✨ Что нового в 27.7.2

- **Семь категорий настроек**: Основные / Игра / Рендерер / Сеть и загрузки / AI / Дополнительные / О программе
- **Отдельные страницы рендереров**: MobileGlues / Ironized Zink / GL4ES, все параметры доступны
- **Избранное объединено**: онлайн-избранное (установка с автозагрузкой зависимостей) и локальный архив
- **Загрузки**: прогресс сверху с подробностями, установка молча в фоне, видеофон снова зациклен

## 🛠️ Возможности

- **AI Agent**: по умолчанию DeepSeek; читает логи, управляет модами, меняет настройки, ставит ресурсы, запускает игру
- **Рендереры**: Авто / MobileGlues / Ironized Zink / GL4ES
- **Ресурсы**: поиск Modrinth / CurseForge, разрешение зависимостей, загрузка, проверка, установка
- **Избранное и архив**: онлайн-избранное плюс приватный архив с дедупликацией SHA-256
- **Защита Fabric API**: добавляется только процессом Fabric, вручную дублировать нельзя

## 📦 Загрузка и сборка

- Загрузка: <https://github.com/zzy89216-gif/ZyNova/releases>
- Сборка: JDK 17 и Android SDK / NDK, затем `./gradlew ZalithLauncher:assembleRelease`
